# À lire en cas d’urgence

Vous avez acheté ce livre, mais vous êtes peut-être déjà dans le feu.

Un artiste vous demande un prix. Un client veut les stems. Une collaboration part dans le flou. Vous avez peur d’envoyer un contrat. Vous avez 200 beats en vrac et vous ne savez pas par où commencer.

Dans ce cas, ne lisez pas tout maintenant.

## Si un artiste veut acheter un beat aujourd’hui

Faites seulement trois choses :

1. Vérifiez quel fichier vous vendez : MP3, WAV, stems ou exclusivité.
2. Envoyez une fiche de prix claire avec ce qui est inclus.
3. Faites accepter une licence écrite avant la livraison finale.

Ne livrez pas les stems complets dans le flou. Ne vendez pas une exclusive sans savoir ce que vous bloquez.

## Si vous êtes noyé dans vos fichiers

Faites seulement trois choses :

1. Choisissez 10 beats maximum.
2. Renommez-les avec la règle `DATE_STYLE_MOOD_BPM_KEY_STATUS`.
3. Mettez-les dans un tableau simple avec BPM, tonalité, statut et prix.

Ne rangez pas tout votre disque dur aujourd’hui. Vous allez abandonner. Commencez par 10 beats.

## Si une collaboration devient floue

Faites seulement trois choses :

1. Demandez qui a fait quoi.
2. Notez les pourcentages dans une split sheet.
3. Gardez une trace écrite de l’accord.

Une conversation orale ne suffit pas. Une capture propre vaut mieux qu’un souvenir différent dans six mois.

## Si vous êtes épuisé

Arrêtez de vouloir tout régler en une nuit.

Votre priorité n’est pas de produire plus. Votre priorité est de rendre votre activité plus respirable.

Aujourd’hui : un beat renommé, une sauvegarde, un message clair. Pas plus.

**Phrase à garder :** un beatmaker organisé ne panique pas moins parce qu’il est plus fort. Il panique moins parce que son système porte une partie du poids.

# ⏱️ Vos 72 premières heures — Plan de démarrage rapide

*Vous venez d’acquérir ce livre. Ne le lisez pas comme un roman. Agissez.*

## Jour 1 — Mettre la main dans le cambouis

Durée : 30 minutes.

* [ ] **Choisissez 1 beat** : le meilleur, le plus récent, celui que vous aimez.
* [ ] **Renommez-le** avec la règle : `DATE_STYLE_MOOD_BPM_KEY_STATUS`.
* [ ] **Notez BPM et tonalité** dans un fichier texte à côté.

➡️ **Pourquoi ?** Un beat bien nommé, c’est un beat qui peut être vendu.

## Jour 2 — Préparer l’export

Durée : 45 minutes.

* [ ] **Structurez le beat** : intro, couplet, refrain, outro.
* [ ] **Exportez MP3** : preview, volume confortable, tag audible.
* [ ] **Exportez WAV** : master, avec marge, pas écrasé.

➡️ **Pourquoi ?** Un beat non exporté proprement ne peut pas être livré.

## Jour 3 — Créer une offre minimale

Durée : 30 minutes.

* [ ] **Écrivez 3 prix** : Standard 49-79 € / Unlimited 149-249 € / Exclusive 700-1500 €.
* [ ] **Listez ce qui est inclus** dans chaque offre : MP3, WAV, stems, droits.
* [ ] **Préparez un message type** : “Beat dispo. 3 offres. Licence incluse. MP3 + WAV + stems. [prix]”.

➡️ **Pourquoi ?** Un prix clair évite les négociations floues.

## Après 72 heures

Vous avez un beat nommé, exporté, tarifé. Ce n’est pas encore une activité. C’est une première brique.

# Introduction — Pourquoi ce livre ?

Vous avez 200 beats sur votre disque dur, mais vous galérez à en vendre un.

Vous ouvrez un vieux projet : `final_prod_artist_v3.wav`.

Quel est le BPM ? Quelle est la tonalité ? Est-ce une version mixée, masterisée, envoyée, vendue ou juste une démo ? Avez-vous les stems ? Avez-vous une version MP3 taggée ? Avez-vous un contrat prêt si quelqu’un veut l’acheter ?

Si vous devez chercher pendant quinze minutes avant de répondre, ce n’est pas seulement un problème d’organisation. C’est un problème business.

Beaucoup de beatmakers produisent beaucoup. Ils ont des dossiers remplis de prods, des loops commencées, des sessions FL Studio, Ableton, Logic Pro ou autres DAW, des exports WAV dans tous les sens, des fichiers nommés “new beat”, “type beat final”, “drill dark v2”, “mix ok”, “master final final”.

Mais quand vient le moment de vendre, tout devient flou.

Le beat est-il prêt ? Quel prix annoncer ? Quels droits donner ? Que se passe-t-il si l’artiste sort le morceau sur Spotify ? Peut-il l’utiliser sur TikTok ? Peut-il monétiser sur YouTube ? Peut-il envoyer le beat à un autre producteur ? Peut-il l’utiliser pour entraîner une IA ? Faut-il signer un contrat ? Faut-il une split sheet ? Faut-il déclarer l’œuvre ?

Ce livre part d’un constat simple : aujourd’hui, le problème de beaucoup de beatmakers n’est pas seulement de produire. C’est de transformer leur créativité en système.

## Ce livre n’est pas un énième guide pour apprendre à faire un beat

Il existe déjà des milliers de tutoriels pour programmer une 808, mixer une snare, trouver un sample, faire un type beat ou reproduire le son d’un artiste connu.

Ce livre part du principe que vous savez déjà produire des beats corrects.

Vous n’avez pas besoin d’être ingénieur du son confirmé. Vous n’avez pas besoin d’avoir un studio professionnel. Vous n’avez pas besoin de maîtriser tous les plugins du marché.

Mais vous devez apprendre à penser comme un indépendant organisé.

Un beatmaker indépendant sérieux ne se contente pas de créer. Il sait :

* classer ses beats ;
* préparer des exports propres ;
* fixer ses prix ;
* expliquer ses licences ;
* suivre ses clients ;
* protéger ses droits ;
* collaborer sans perdre ses splits ;
* utiliser les plateformes sans dépendre entièrement d’elles ;
* communiquer sans spammer ;
* utiliser l’IA comme assistant, pas comme béquille.

L’objectif de ce livre est clair : vous faire passer du statut de beatmaker créatif à celui de beatmaker organisé, visible et rentable.

Rentable ne veut pas dire riche du jour au lendemain. Rentable veut dire : vous savez ce que vous vendez, à qui vous le vendez, dans quelles conditions, avec quels fichiers, quels droits et quel suivi.

**À retenir :** avant de chercher plus de visibilité, rendez votre catalogue exploitable.

# Partie 1 — Le métier en 2027

## Problème

Beaucoup de beatmakers perdent de l’argent parce que leur rôle n’est pas clair.

Un artiste vous appelle “producteur”. Un autre vous appelle “compositeur”. Un manager vous parle de “prod”. Une plateforme parle de “licence”. Une société de droits parle d’auteur, de compositeur, d’éditeur ou de producteur phonographique.

Si vous ne savez pas quel rôle vous occupez, vous ne savez pas quels droits défendre.

> *👶 Pour Léo : cette partie doit te calmer. Tu n’as pas besoin d’être une légende pour être sérieux. Tu dois juste savoir ce que tu fais et ce que tu vends.*

> *💼 Pour Sarah : applique cette partie avant de renégocier tes prix. Un prix sans rôle clair devient fragile.*

> *🌍 Pour Mamadou : note chaque terme anglais équivalent. À l’international, les mots flous coûtent cher.*

> *💔 Pour Camille : tu n’as pas à porter tous les rôles. Tu dois seulement clarifier ceux que tu assumes vraiment.*

## 1.1 Beatmaker, producteur, compositeur : clarifier son rôle

### Les définitions simples

| Rôle                                        | Ce qu’il fait                                                         | Exemple concret                                                    | Risque si c’est flou                           |
| ------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------- |
| Beatmaker                                   | Crée l’instrumental, le rythme, l’ambiance sonore                     | Vous créez un beat trap, afro, drill ou R&B                        | Être payé une seule fois sans garder de droits |
| Compositeur                                 | Crée la musique : mélodie, harmonie, structure                        | Vous composez la progression d’accords et la topline instrumentale | Ne pas être crédité comme auteur-compositeur   |
| Producteur musical / réalisateur artistique | Supervise la direction artistique, l’enregistrement, les choix finaux | Vous accompagnez l’artiste en studio et restructurez le morceau    | Être traité comme simple vendeur de fichier    |
| Producteur phonographique                   | Finance ou exploite le master selon les contrats                      | Vous financez l’enregistrement final et exploitez le master        | Confusion avec le rôle de beatmaker            |
| Topliner                                    | Crée la mélodie vocale et parfois les paroles                         | Une chanteuse pose une mélodie sur votre beat                      | Splits non définis                             |

Dans la pratique, une même personne peut occuper plusieurs rôles. Vous pouvez être beatmaker et compositeur. Vous pouvez devenir réalisateur artistique si vous accompagnez l’artiste dans la structure du morceau, les prises voix et la direction sonore.

Mais il faut l’écrire.

Un rôle non écrit devient un malentendu. Un malentendu devient une dispute. Une dispute devient parfois une perte d’argent.

### Pourquoi cette confusion coûte de l’argent

Si vous envoyez un beat et que l’artiste sort le morceau sans accord écrit, plusieurs questions apparaissent :

* êtes-vous crédité comme compositeur ?
* avez-vous vendu seulement une licence ou cédé vos droits ?
* gardez-vous une part d’édition ?
* touchez-vous des royalties ?
* l’artiste peut-il modifier le beat ?
* peut-il utiliser le beat dans une publicité ?
* peut-il l’envoyer à une IA ou à une équipe de remix ?

Sans réponse écrite, tout devient négociation après coup. Et une négociation après succès est toujours plus compliquée qu’un accord avant sortie.

**Erreur à éviter :** croire qu’un paiement PayPal suffit à définir les droits. Un paiement prouve qu’il y a eu transaction. Il ne précise pas forcément ce qui a été autorisé.

### Action aujourd’hui

Écrivez votre définition en deux lignes :

> Je suis beatmaker spécialisé dans ________. Je fournis des instrumentales prêtes à être utilisées par ________, avec des licences claires et des fichiers professionnels.

Exemple :

> Je suis beatmaker spécialisé dans les prods trap mélodiques et afro urbaines. Je fournis aux artistes indépendants des instrumentales prêtes à sortir, avec exports propres, licences claires et suivi professionnel.

## 1.2 Les cinq erreurs qui bloquent la plupart des beatmakers

### Erreur 1 — Produire sans système de nommage

Un beat non nommé correctement devient invisible dans votre propre disque dur.

Mauvais exemple :

`beat_final_v2.wav`

Bon exemple :

`2027-05-16_TRAP_DARK_140BPM_Fmin_AVAILABLE.wav`

Un bon nom vous donne immédiatement la date, le style, l’ambiance, le BPM, la tonalité et le statut.

### Erreur 2 — Vendre sans licence claire

Un artiste ne doit pas acheter “un beat”. Il doit acheter un droit d’utilisation défini.

Une licence doit préciser :

* ce que l’artiste peut faire ;
* ce qu’il ne doit pas faire ;
* la durée ;
* le territoire ;
* les limites éventuelles ;
* les droits sur YouTube, TikTok, synchronisation, publicité ;
* le crédit à afficher ;
* les conditions d’exclusivité ;
* les règles sur l’IA et les samples.

### Erreur 3 — Fixer ses prix au hasard

Beaucoup de beatmakers baissent leurs prix parce qu’ils ont peur de perdre la vente. Le problème n’est pas seulement le montant. C’est l’absence de grille.

Si vous n’avez pas trois offres claires, vous négociez dans le vide.

### Erreur 4 — Ne pas suivre les clients

Un artiste qui a acheté une fois doit pouvoir acheter à nouveau. Mais si vous ne notez pas son nom, son style, la date d’achat, la licence et le lien du morceau sorti, vous perdez la relation.

Un client non suivi est souvent une vente perdue.

### Erreur 5 — Ignorer les splits

Quand plusieurs personnes participent à un morceau, il faut définir la répartition des droits. Une split sheet simple évite des mois de tension.

Une split sheet est un document qui indique qui possède quel pourcentage sur l’œuvre. Ce n’est pas un signe de méfiance. C’est une preuve de respect.

### Erreur 6 — Ignorer les droits voisins et les sociétés de gestion

Beaucoup de beatmakers comprennent à peu près la vente d’une licence, mais oublient l’autre étage : l’enregistrement lui-même.

Quand un morceau sort officiellement, il ne crée pas seulement une œuvre musicale. Il crée aussi un enregistrement, donc un master. Sur ce master, il peut exister des droits voisins. Ces droits peuvent concerner notamment les producteurs phonographiques et les artistes-interprètes, selon les pays, les contrats et les exploitations.

Le danger : vendre un beat, laisser l’artiste sortir le morceau, ne pas noter l’ISRC, ne pas savoir qui est producteur du master, ne pas savoir qui déclare quoi, puis découvrir trop tard que des revenus existent mais que personne ne sait les récupérer.

Un beatmaker n’a pas toujours vocation à devenir producteur phonographique. Mais dès qu’il finance, organise, distribue ou exploite un enregistrement, il doit comprendre ce terrain.

**Règle simple :** droits d’auteur = composition. Droits voisins = enregistrement et interprétation. Distribution = mise en ligne. Ce sont trois couches différentes.

**À retenir :** les problèmes de droits viennent rarement d’une mauvaise intention au départ. Ils viennent souvent d’un manque de clarté.

## 1.3 Pourquoi “juste produire” ne suffit plus

L’IA générative a changé le volume de production. Il est devenu plus facile de créer des idées musicales rapidement. Mais produire plus vite ne veut pas dire construire une activité plus solide.

L’IA peut aider à :

* générer des idées ;
* classer des fichiers ;
* reformuler des descriptions ;
* analyser des tendances ;
* créer des variantes ;
* préparer des messages de prospection.

Mais elle ne remplace pas :

* votre goût ;
* votre culture musicale ;
* votre relation avec les artistes ;
* votre capacité à comprendre une direction ;
* votre sens du timing ;
* votre identité sonore ;
* votre responsabilité juridique.

| Ce que l’IA fait bien            | Ce que le beatmaker humain doit garder |
| -------------------------------- | -------------------------------------- |
| Générer beaucoup d’idées         | Choisir ce qui mérite d’exister        |
| Proposer des variantes           | Construire une signature               |
| Accélérer des tâches répétitives | Comprendre un artiste                  |
| Aider à organiser                | Décider d’une stratégie                |
| Suggérer des textes ou tags      | Assumer les droits, contrats et déclarations |
| Accélérer la mise en ligne | Comprendre distribution, ISRC, UPC et droits voisins |

**À retenir :** l’IA augmente les beatmakers organisés et noie les beatmakers dispersés.

# Partie 2 — S’équiper sans se disperser

## Problème

Beaucoup de beatmakers passent plus de temps à comparer les logiciels qu’à finir des beats.

FL Studio, Ableton Live, Logic Pro, Pro Tools, Reaper : tous permettent de produire sérieusement. Le meilleur DAW n’est pas celui qui a le plus de fonctions. C’est celui dans lequel vous terminez vos morceaux.

> *👶 Pour Léo : choisis un DAW principal et garde-le six mois. Tu n’as pas un problème d’outil. Tu as un problème de finition.*

> *💼 Pour Sarah : investis seulement dans ce qui réduit un blocage réel : sauvegarde, casque fiable, template, workflow.*

> *🌍 Pour Mamadou : ton setup doit produire vite, livrer proprement et archiver sans erreur. L’international ne pardonne pas les fichiers perdus.*

> *💔 Pour Camille : n’achète pas du matériel pour calmer ton anxiété. Crée un système qui réduit la fatigue.*

## 2.1 Quel DAW pour quel usage ?

Les fonctions d’assistance, d’IA, de séparation de stems, de mastering assisté ou de suggestion créative évoluent rapidement selon les versions. Vérifiez toujours les fonctionnalités actuelles sur les sites officiels avant achat.

| DAW          | Profil adapté                                 | Points forts                                              | Limites                                                 |
| ------------ | --------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------- |
| FL Studio    | Beatmaking rapide, trap, drill, hip-hop       | Séquenceur intuitif, piano roll puissant, workflow rapide | Peut encourager l’accumulation de loops si mal organisé |
| Ableton Live | Live, électronique, expérimentation           | Session view, manipulation audio, performance             | Courbe d’apprentissage particulière                     |
| Logic Pro    | Utilisateurs Mac, composition, enregistrement | Bon rapport fonctionnalités/prix, instruments intégrés    | Mac uniquement                                          |
| Pro Tools    | Studio, édition audio, enregistrement pro     | Standard dans beaucoup de studios                         | Moins naturel pour débuter en beatmaking pur            |
| Reaper       | Budget limité, personnalisation               | Léger, abordable, flexible                                | Interface moins clé en main                             |

### La règle

Choisissez un DAW principal et gardez-le au moins six mois.

Pendant cette période, l’objectif n’est pas de trouver mieux. L’objectif est de finir plus.

**Erreur à éviter :** changer de DAW chaque fois que vous voyez un producteur connu utiliser un autre logiciel.

## 2.2 Matériel : le strict minimum, les bons investissements

Beaucoup de beatmakers achètent du matériel pour se sentir professionnels avant d’avoir un système professionnel.

Un clavier MIDI ne compense pas un mauvais catalogue. Une interface chère ne remplace pas une bonne routine. Des enceintes coûteuses ne servent à rien si votre pièce n’est pas traitée et si vos fichiers sont mal exportés.

### Configuration minimale

Pour commencer sérieusement :

* un ordinateur stable ;
* un DAW maîtrisé ;
* un bon casque ;
* une sauvegarde externe ;
* une bibliothèque de sons propre ;
* éventuellement une petite interface audio si vous enregistrez voix ou instruments.

### Trois configurations réalistes

| Budget | Objectif            | Priorités                                                                       |
| ------ | ------------------- | ------------------------------------------------------------------------------- |
| 200 €  | Démarrer proprement | Casque correct, disque externe, quelques sons fiables                           |
| 800 €  | Home studio sérieux | Interface audio, casque, contrôleur MIDI simple, sauvegarde cloud               |
| 2000 € | Setup avancé        | Moniteurs, traitement acoustique léger, interface supérieure, stockage sécurisé |

Le meilleur investissement n’est pas toujours visible. Une sauvegarde, un disque fiable et un espace de travail organisé rapportent parfois plus qu’un nouveau synthé virtuel.

**À retenir :** achetez ce qui réduit vos blocages, pas ce qui flatte votre image.

## 2.3 Plugins et samples : éviter l’accumulation

Trop de plugins ralentissent la décision. Trop de samples rendent le choix plus difficile. Trop d’options tuent le workflow.

### La règle “un besoin, un outil principal”

Gardez une sélection courte :

* un EQ principal ;
* un compresseur principal ;
* une reverb principale ;
* un delay principal ;
* un synthé principal ;
* une banque de drums principale ;
* une banque mélodique principale.

Le reste peut rester installé, mais ne doit pas être votre premier réflexe.

### Organisation des samples

Créez un dossier maître :

`SAMPLES_MASTER`

Avec des sous-dossiers :

* `Drums_Kicks`
* `Drums_Snares`
* `Drums_Hats`
* `808_Bass`
* `Melodic_Loops`
* `Vocals`
* `FX`
* `Percussions`
* `One_Shots`
* `Favorites`

Dans chaque dossier, supprimez ou archivez ce que vous n’utilisez jamais.

### Action aujourd’hui

* Choisissez votre DAW principal pour les six prochains mois.
* Créez un template minimal avec drums, 808, mélodie, FX, bus drums, bus mélodie, master léger.
* Archivez 20 % de vos sons inutilisés.
* Créez une sauvegarde externe de vos projets importants.

## 🧠 Coin du psy — “Il me faut plus de matos pour réussir”

**La peur :** “Je n’ai pas assez de matériel. Je ne peux pas être crédible.”

**La réalité :** Le matériel donne du confort, pas une direction. Un beat bien structuré, bien nommé et bien livré vaut mieux qu’un beat fait avec 400 plugins mais impossible à retrouver. Le setup parfait est souvent une excuse propre pour éviter la vente.

**À répéter :** “Je finis avec ce que j’ai. J’achète seulement ce qui débloque une action.”

## Récap’ 30 secondes

* Le meilleur DAW est celui dans lequel vous finissez vos beats.
* Un setup simple mais stable vaut mieux qu’un setup impressionnant mais chaotique.
* Les samples doivent accélérer la création, pas vous noyer.

# Partie 3 — Créer des beats vendables

## Problème

Beaucoup de beatmakers commencent vite, mais ne finissent pas. Ils ont des loops de huit mesures, des idées intéressantes, des brouillons, mais peu de beats vraiment prêts à être envoyés.

Un beat vendable n’est pas forcément parfait. C’est un beat clair, structuré, exporté et exploitable par un artiste.

> *👶 Pour Léo : ton objectif n’est pas de faire le meilleur beat de ta vie. Ton objectif est de finir un beat exploitable.*

> *💼 Pour Sarah : tes beats doivent sortir sous forme de packs propres, pas rester coincés dans ton DAW.*

> *🌍 Pour Mamadou : prépare dès maintenant des versions instrumentales, stems et metadata. Les marchés sérieux demandent des fichiers propres.*

> *💔 Pour Camille : finis avant d’optimiser. Le perfectionnisme déguisé en exigence reste du blocage.*

## 3.1 Workflow simple pour sortir un beat propre en deux heures

Un beat vendable doit donner envie d’écrire. Il doit respirer. Il doit proposer une direction claire.

### Workflow en deux heures

| Temps       | Étape             | Objectif                                  |
| ----------- | ----------------- | ----------------------------------------- |
| 0-20 min    | Drums             | Créer le groove principal                 |
| 20-40 min   | Basse / 808       | Installer l’énergie                       |
| 40-70 min   | Mélodie / texture | Donner l’identité                         |
| 70-100 min  | Arrangement       | Créer intro, couplet, refrain, variations |
| 100-115 min | Mix léger         | Nettoyer volumes, EQ, dynamique           |
| 115-120 min | Export brouillon  | Créer MP3 privé pour écoute               |

Ce workflow n’est pas une prison. C’est une contrainte utile. Si vous êtes bloqué plus de vingt minutes sur un son, avancez. Vous pourrez améliorer plus tard.

**Erreur à éviter :** passer trois heures sur un hi-hat avant d’avoir structuré le morceau.

## 3.2 Structure, arrangement, variations

Un artiste n’achète pas une loop. Il achète une base de morceau.

Même si un beat repose sur une boucle, il doit respirer. Il doit laisser de la place à la voix. Il doit créer des moments.

### Structure simple

* Intro : 4 à 8 mesures
* Couplet : 16 mesures
* Pré-refrain ou variation : 4 à 8 mesures
* Refrain : 8 mesures
* Couplet 2 : 16 mesures
* Refrain 2 : 8 mesures
* Outro : 4 à 8 mesures

### Variations utiles

Toutes les 8 mesures, modifiez quelque chose :

* retirer la 808 ;
* couper les hats ;
* ajouter un riser ;
* filtrer la mélodie ;
* changer la snare ;
* ajouter un silence ;
* doubler une mélodie ;
* créer une transition.

### Checklist “mon beat est-il prêt ?”

* [ ] Il a une intro claire.
* [ ] Il laisse de la place à la voix.
* [ ] Il contient au moins trois variations.
* [ ] Il a une énergie identifiable.
* [ ] Il peut être compris sans explication.
* [ ] Il existe en version MP3 et WAV.
* [ ] Le BPM et la tonalité sont notés.

## 3.3 Les exports qui font la différence

Vous pouvez perdre une vente avec un mauvais export.

Un artiste intéressé veut avancer vite. S’il doit vous redemander le WAV, les stems, le BPM, la tonalité ou une version sans tag, vous donnez une impression amateur.

### Pack minimal d’export

Pour chaque beat prêt à vendre, préparez :

* MP3 320 kbps avec tag audio ou watermark ;
* WAV 24 bit ;
* stems séparés ;
* version courte pour réseaux sociaux ;
* fichier texte avec BPM, tonalité, crédits, conditions de licence ;
* contrat ou lien vers licence.

### LUFS : comprendre sans se perdre

LUFS signifie “Loudness Units Full Scale”. C’est une mesure du volume perçu. En clair : ce n’est pas seulement le pic le plus fort. C’est la sensation globale de volume.

Vous n’avez pas besoin de devenir ingénieur mastering. Vous devez surtout livrer des fichiers cohérents selon leur usage.

### Repères unifiés

| Usage                  | Objectif                                           | Repère pratique                                                                      |
| ---------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Preview MP3            | Donner envie, protéger le beat, écouter facilement | Volume confortable, tag possible, pas d’écrasement excessif                          |
| WAV pour artiste       | Permettre enregistrement, mix ou sortie propre     | Garder de la marge, éviter un master trop agressif                                   |
| Stems                  | Permettre un vrai mix                              | Export propre, mêmes débuts de fichiers, noms clairs, pas d’effet master destructeur |
| Réseaux sociaux        | Impact rapide                                      | Version courte, intro efficace, volume stable                                        |
| Sync / placement image | Exploitation professionnelle                       | Droits propres, variantes, stems, metadata complète                                  |

Le but n’est pas de respecter un chiffre comme une religion. Le but est que le fichier soit exploitable.

**Règle simple :** une preview doit donner envie. Un WAV doit laisser de la marge. Des stems doivent être propres et synchronisés.

### Exemple de dossier

`BEAT_NAME_140BPM_Fmin`

* `01_MP3_PREVIEW`
* `02_WAV_MASTER`
* `03_STEMS`
* `04_SHORT_VERSION`
* `05_LICENSE_INFO`
* `06_COVER_ART_OPTIONAL`

**À retenir :** un beat prêt à vendre est un beat prêt à livrer.

### Action aujourd’hui

* Choisissez un beat.
* Structurez-le avec au moins intro, couplet, refrain, outro.
* Exportez MP3 + WAV.
* Notez BPM, tonalité et mood.
* Rangez-le dans un dossier propre.

## 🧠 Coin du psy — “Mon beat n’est jamais assez bon”

**La peur :** “Je ne peux pas le vendre. Il n’est pas parfait.”

**La réalité :** Le marché ne vous demande pas un chef-d’œuvre absolu à chaque export. Il demande un beat clair, utilisable, avec une vibe. Un artiste peut préférer une prod simple mais inspirante à une prod ultra travaillée qui ne laisse aucune place à la voix.

**À répéter :** “Je finis d’abord. J’améliore ensuite.”

## Récap’ 30 secondes

* Un beat vendable doit être structuré, pas seulement stylé.
* Les variations donnent envie d’écrire.
* Les exports propres font vendre plus vite que les excuses techniques.

# Partie 4 — Organiser son catalogue comme un pro

## Problème

Votre catalogue est votre actif principal.

Pas votre dernier plugin. Pas votre logo. Pas votre nombre de followers. Votre catalogue.

Un catalogue bien organisé vous permet de retrouver rapidement une prod, envoyer le bon fichier, suivre les ventes, relancer les artistes, déclarer les œuvres, sécuriser vos droits et gagner du temps.

Un catalogue désorganisé transforme chaque opportunité en stress.

> *👶 Pour Léo : cette partie est ta priorité absolue. Ne juge pas tes beats. Range-les.*

> *💼 Pour Sarah : ton prochain palier de revenus vient de ton tableau catalogue, pas d’un nouveau pack de drums.*

> *🌍 Pour Mamadou : un marché étranger ne peut pas travailler avec un catalogue flou.*

> *💔 Pour Camille : organiser, c’est réduire la charge mentale. Ce n’est pas devenir robotique.*

## 4.1 Système de nommage

Vous cherchez un beat mélodique en 140 BPM. Vous savez qu’il existe. Vous l’avez fait il y a trois mois. Mais il s’appelle peut-être :

* `newtrap.wav`
* `dark_final.wav`
* `artist_type_beat.wav`
* `finalfinal2.wav`
* `beat jeudi.wav`

Vous perdez du temps, et parfois vous abandonnez.

### La règle de nommage

Utilisez une structure fixe :

`DATE_STYLE_MOOD_BPM_KEY_STATUS`

Exemple :

`2027-05-16_TRAP_DARK_140BPM_Fmin_AVAILABLE.wav`

Chaque champ a un rôle :

* Date : retrouver la période de création.
* Style : trap, drill, afro, R&B, pop urbaine.
* Mood : dark, sad, energetic, smooth, cinematic.
* BPM : tempo.
* Key : tonalité.
* Status : available, sent, sold, exclusive, draft.

### Statuts recommandés

| Statut    | Signification            |
| --------- | ------------------------ |
| DRAFT     | Idée non finalisée       |
| READY     | Beat prêt à être exporté |
| AVAILABLE | Disponible à la vente    |
| SENT      | Envoyé à un artiste      |
| LEASED    | Vendu en non-exclusif    |
| EXCLUSIVE | Vendu en exclusif        |
| LOCKED    | À ne plus envoyer        |

**Erreur à éviter :** utiliser “final” comme statut. “Final” ne veut rien dire si vous ne savez pas final pour quoi.

## 4.2 Tableau de bord catalogue

Même avec de bons noms de fichiers, vous avez besoin d’une vue globale. Votre disque dur ne suffit pas. Il vous faut un tableau de bord.

### Colonnes recommandées

| Colonne           | Exemple                        |
| ----------------- | ------------------------------ |
| Titre             | Midnight Pressure              |
| Style             | Trap mélodique                 |
| Mood              | Dark / émotionnel              |
| BPM               | 140                            |
| Tonalité          | F minor                        |
| Statut            | Available                      |
| Prix standard     | 49 €                           |
| Prix premium      | 149 €                          |
| Prix exclusif     | 700 €                          |
| Lien MP3 privé    | URL                            |
| Lien WAV          | URL interne                    |
| Stems prêts ?     | Oui / Non                      |
| Envoyé à          | Nom artiste                    |
| Date d’envoi      | 2027-05-16                     |
| Réponse           | Intéressé / non / relance      |
| Licence vendue    | Standard / Premium / Exclusive |
| Contrat signé ?   | Oui / Non                      |
| Facture envoyée ? | Oui / Non                      |

Vous pouvez créer ce tableau dans Notion, Airtable, Google Sheets ou Excel. Le meilleur outil est celui que vous ouvrez vraiment.

**À retenir :** votre catalogue doit devenir consultable en moins de deux minutes.

## 4.3 Exports et pack de livraison

Un artiste paie. Vous commencez à chercher les fichiers. Vous devez refaire un export. Vous ne trouvez pas les stems. Vous hésitez sur la version. Vous envoyez un dossier incomplet.

Ce moment doit être fluide.

### Pack de livraison professionnel

Créez un dossier modèle :

* 2 supports différents ;

1. ordinateur principal ;

# Partie 5 — Vendre ses beats proprement

## Problème

Beaucoup de beatmakers ne vendent pas mal parce que leurs beats sont mauvais. Ils vendent mal parce que leur offre est floue.

Un artiste demande : “C’est combien ?”

Vous répondez : “Ça dépend.”

À partir de là, vous avez déjà perdu une partie de votre autorité.

> *👶 Pour Léo : tu dois arrêter de vendre à la tête du client. Même à petit prix, tu dois annoncer clairement ce qui est inclus.*

> *💼 Pour Sarah : cette partie doit augmenter tes revenus. Pas en devenant dure, mais en devenant claire.*

> *🌍 Pour Mamadou : tes licences doivent être compréhensibles en français et en anglais. Sinon, tu vas perdre des deals ou signer n’importe quoi.*

> *💔 Pour Camille : fixer un cadre ne fait pas fuir les bons artistes. Ça filtre les situations qui te fatiguent.*

## 5.1 Licence, cession, exclusivité : ne mélangez pas tout

Un beat ne se vend pas toujours de la même manière.

**Note sur les prix :** les montants indiqués dans ce livre sont des repères indicatifs. Ils ne remplacent pas votre réalité de marché, votre niveau, votre positionnement, votre pays, votre fiscalité, votre expérience, votre catalogue et la valeur du client. Utilisez-les comme base de réflexion, pas comme vérité absolue.

### Licence non exclusive

Vous autorisez un artiste à utiliser le beat selon certaines conditions, mais vous pouvez encore vendre ce beat à d’autres artistes.

Exemple : licence standard à 49 € ou 79 €, incluant MP3 + WAV, avec limites d’écoutes, de streams ou de monétisation selon votre modèle.

### Licence unlimited

Vous autorisez un usage plus large, souvent sans limite de streams, mais toujours non exclusif.

Exemple : 149 € ou 199 €, avec MP3 + WAV + stems, sans limite de streams, mais sans droit de revente ni synchronisation publicitaire sans accord.

### Licence exclusive

Vous accordez à un artiste une exclusivité d’exploitation selon les conditions prévues. Vous devez retirer le beat de la vente ou le bloquer.

Exemple : 700 € à 1500 € selon votre niveau, le fichier livré, les stems, les droits inclus et la valeur du client.

### Cession

Une cession signifie que vous transférez certains droits. C’est plus lourd qu’une licence. Ne signez jamais une cession sans comprendre précisément ce que vous abandonnez.

**Règle simple :** licence = autorisation d’utiliser. Cession = transfert de droits. Ce n’est pas la même chose.

## 5.2 Créer une grille de prix claire

Vous devez proposer trois offres simples.

| Offre     |  Prix indicatif | Inclus                                  | Pour qui                             |
| --------- | --------------: | --------------------------------------- | ------------------------------------ |
| Standard  |     49 € à 79 € | MP3 + WAV, usage limité                 | Artiste débutant sérieux             |
| Unlimited |   149 € à 249 € | MP3 + WAV + stems, usage large          | Artiste qui veut sortir proprement   |
| Exclusive | 700 € à 1500 €+ | Exclusivité, stems, retrait de la vente | Artiste / label / projet prioritaire |

Ces prix ne sont pas des lois. Ils donnent un cadre. Adaptez selon votre niveau, votre marché, votre notoriété, votre qualité d’export et vos objectifs.

**Erreur à éviter :** vendre une exclusive à 100 € parce que vous avez peur de perdre le client. Une exclusive bloque un actif. Elle doit être payée comme un actif.

## 5.3 Ce qu’une licence doit préciser

Votre licence doit préciser :

* le titre du beat ;
* les noms des parties ;
* le type de licence ;
* les fichiers inclus ;
* la durée ;
* le territoire ;
* les limites d’exploitation ;
* les plateformes autorisées ;
* le crédit à afficher ;
* les règles sur les samples ;
* les règles sur l’IA ;
* les conditions de paiement ;
* les conséquences en cas de dépassement.

### Exemple de phrase simple

> Cette licence autorise l’artiste à utiliser le beat intitulé “Midnight Pressure” dans un morceau original, distribué sur les plateformes numériques, selon les limites prévues dans l’offre choisie. Le beatmaker reste titulaire de ses droits, sauf mention contraire écrite.

C’est simple. C’est clair. Ça protège tout le monde.

## 5.4 Cas réel anonymisé — Thomas, Lyon, 24 ans

Thomas produisait de la trap sombre depuis sa chambre. Il avait environ 80 beats. Aucun n’était classé. Il gagnait parfois 200 € par mois, puis plus rien pendant deux mois.

Il disait : “Je pensais que c’était impossible de vivre de mes beats. Je pensais que le problème, c’était ma visibilité.”

La réalité : son catalogue était inutilisable.

### Ce qu’il a fait

Mois 1 : il a renommé ses 80 beats. Cela lui a pris 15 heures. C’était long, pénible, presque humiliant. Mais à la fin, il savait enfin ce qu’il possédait.

Mois 2 : il a créé une fiche de prix avec trois offres : standard, unlimited, exclusive. Il a perdu deux ventes parce que les artistes voulaient payer moins. Mais il a signé une exclusive à 650 €.

Mois 3 : il a contacté cinq artistes ivoiriens avec des messages personnalisés. Pas 200 DM copiés-collés. Cinq vrais messages. Il a vendu trois licences non exclusives à 80 €.

### Résultat à 6 mois

Thomas est passé à environ 1200 € par mois de revenu beatmaking, avec une opportunité de sync à 300 €.

Son erreur à ne pas reproduire : il a négligé les splits pendant deux mois. Une collaboration a failli capoter parce que personne n’avait écrit les pourcentages au départ.

Sa phrase : “Je pensais que vendre plus voulait dire poster plus. En vrai, j’ai vendu plus quand j’ai rangé mes fichiers et arrêté de négocier dans le flou.”

## 5.5 Cas réel anonymisé — Aïcha, Paris, 29 ans

Aïcha avait 200 beats. Elle vendait déjà en France, mais elle plafonnait. Elle avait une vraie identité sonore : afro, R&B, pop urbaine, textures douces. Les artistes aimaient ses prods, mais ses revenus restaient trop dépendants de trois clients réguliers.

Elle disait : “Je pensais que l’international était réservé aux producteurs déjà connectés.”

La réalité : elle avait déjà le son. Il lui manquait les passerelles.

### Ce qu’elle a fait

Elle a traduit son contrat en anglais avec un outil de traduction, puis l’a fait relire. Elle a préparé une page privée avec 12 beats propres : BPM, tonalité, mood, version MP3, prix clair.

Elle a ciblé deux marchés : Nigeria et Brésil. Pas tout le monde. Deux marchés, deux semaines de recherche, des messages courts, respectueux et personnalisés.

Elle n’a pas commencé par vendre une exclusive. Elle a commencé par proposer des licences non exclusives et des collaborations cadrées.

### Résultat à 6 mois

Elle a augmenté ses revenus d’environ 70 %. Elle a lancé trois collaborations internationales. Elle a aussi compris qu’un marché étranger ne se gagne pas avec un message automatique. Il se gagne avec un catalogue propre, des mots simples et de la patience.

Sa phrase : “Je pensais que je devais parler parfaitement anglais. En fait, je devais surtout arrêter d’envoyer des liens en vrac.”


## 5.6 Cas réel anonymisé — Mamadou, Marseille, 31 ans

Mamadou vendait déjà des beats en France. Son catalogue était propre, ses exports étaient bons, et il avait une vraie couleur : rap sombre, afro trap, drill mélodique. Pourtant, dès qu’un artiste étranger voulait sortir un titre, tout devenait flou.

Il savait vendre une licence. Il ne savait pas toujours répondre à ces questions :

* qui distribue le morceau ?
* qui possède le master ?
* quel ISRC sera utilisé ?
* le beatmaker sera-t-il crédité comme compositeur ?
* y a-t-il une split sheet ?
* qui peut déclarer les droits voisins ?
* que se passe-t-il si le morceau passe en radio, club, web TV ou playlist éditoriale ?

Son problème n’était pas le son. Son problème était l’après-vente.

### Ce qu’il a fait

Il a ajouté trois colonnes à son catalogue : `ISRC`, `Distributeur`, `Droits voisins / société concernée`.

Il a arrêté d’envoyer simplement “voici le WAV”. À chaque sortie sérieuse, il demandait maintenant :

> Le morceau sera-t-il distribué officiellement ? Si oui, merci de me transmettre l’ISRC, le distributeur, la date de sortie, les crédits exacts et la split sheet validée.

Il a aussi préparé deux modèles : un contrat de collaboration et un message simple pour clarifier les droits voisins.

### Résultat à 6 mois

Il n’a pas “récupéré de l’argent magique”. Il a surtout arrêté de perdre la trace de ses enregistrements. Sur trois sorties internationales, deux étaient enfin documentées proprement. Cela lui a permis de parler avec plus de sérieux à un éditeur, un manager et un distributeur.

Sa phrase : “Je pensais que les droits voisins étaient un truc de label. En fait, c’est surtout un truc qu’il faut comprendre avant que le morceau parte dans la nature.”

## 5.7 Plateformes de leasing : utiles, mais pas suffisantes

BeatStars, Airbit, Traktrain ou d’autres plateformes peuvent vous aider à présenter et vendre vos beats. Elles ne remplacent pas votre stratégie.

Une plateforme peut gérer une page, un player, un paiement et parfois des modèles de licence. Mais elle ne sait pas à votre place :

* si votre sample est autorisé ;
* si votre split est clair ;
* si vous devez bloquer un beat vendu en exclusif ;
* si l’artiste a déposé le morceau dans Content ID ;
* si un ISRC a été créé ;
* si une sortie officielle doit être suivie dans votre catalogue.

### La bonne posture

Utilisez les plateformes comme une boutique. Pas comme un cerveau.

Votre vrai système reste votre catalogue maître. Si vous vendez sur trois plateformes mais que votre tableau central n’est pas à jour, vous créez un risque : vendre deux fois une exclusivité, perdre une preuve, oublier une relance, ne pas savoir quelle version a été livrée.

### Action simple

Pour chaque beat en ligne, vérifiez :

* titre identique partout ;
* BPM et tonalité exacts ;
* prix cohérents ;
* statut à jour ;
* lien vers licence ;
* mention claire des usages interdits ;
* retrait immédiat si vente exclusive.


## 5.8 Paiement, facture, preuve

Un paiement doit être traçable. Évitez les arrangements flous.

Conservez :

* preuve de paiement ;
* facture ou reçu ;
* contrat ou licence ;
* échanges importants ;
* fichiers livrés ;
* date de livraison ;
* version exacte du beat.

Un bon dossier client doit vous permettre de répondre en deux minutes à cette question : “Qu’est-ce que j’ai vendu, à qui, quand, pour quel usage ?”

## 🧠 Coin du psy — “Un contrat va faire peur à l’artiste”

**La peur :** “Si j’envoie un contrat, l’artiste va croire que je suis compliqué ou que je ne lui fais pas confiance.”

**La réalité :** Un bon contrat ne casse pas la relation. Il protège la relation. Les artistes sérieux préfèrent savoir ce qu’ils peuvent faire plutôt que découvrir les limites au dernier moment. Ce qui fait peur, ce n’est pas le contrat. C’est le contrat incompréhensible, agressif ou envoyé trop tard.

**À répéter :** “Le cadre ne tue pas la vibe. Il protège la vibe.”

## Récap’ 30 secondes

* Vous ne vendez pas “un beat”. Vous vendez un droit d’utilisation.

* Un contrat simple rassure les bons clients et filtre les mauvais plans.

# Partie 6 — Protéger ses droits sans devenir juriste

## Problème

Les droits font peur parce qu’ils semblent compliqués. Mais l’absence de droits écrits coûte plus cher que l’effort de comprendre les bases.

Vous n’avez pas besoin de devenir avocat. Vous devez savoir quand poser une question, quand écrire un accord et quand demander un avis professionnel.

> *👶 Pour Léo : commence par écrire ce que tu autorises. Même une page simple vaut mieux qu’un DM flou.*

> *💼 Pour Sarah : tes ventes doivent laisser une trace. Sinon, ton activité reste fragile.*

> *🌍 Pour Mamadou : à l’international, rien ne doit rester uniquement oral.*

> *💔 Pour Camille : parler de droits n’est pas être froide. C’est éviter les conflits qui épuisent.*

## 6.1 Les droits à comprendre simplement

### Composition

La composition concerne la musique écrite ou créée : mélodie, harmonie, structure, éléments musicaux originaux.

Si vous composez le beat, vous pouvez avoir des droits sur la composition.

### Master

Le master est l’enregistrement final exploité commercialement. Quand un artiste pose sa voix sur votre beat et sort le morceau, il y a un master.

### Publishing / édition

Le publishing concerne les droits liés à la composition et leur exploitation. C’est un sujet plus avancé, mais vous devez savoir qu’il existe.

### Royalties

Les royalties sont des revenus issus de l’exploitation d’une œuvre ou d’un enregistrement. Elles peuvent venir de plateformes, diffusions, synchros, droits voisins, sociétés de gestion selon les cas.


### Schéma visuel — Les trois couches de droits

Un morceau officiellement sorti n’est pas un seul bloc. Il repose sur plusieurs couches. Quand vous comprenez ces couches, vous savez mieux quoi déclarer, quoi demander et quoi protéger.

![Schéma visuel des 3 couches de droits](schema_visuel_3_couches_droits_v8.png)

*Note de mise en page : intégrer ici l’infographie noir et blanc fournie dans le pack V13 sous le nom `schema_visuel_3_couches_droits_v11.png`. Dans la version PDF, cette image peut être utilisée en pleine page ou en encadré premium avant le schéma textuel.*

```text
MORCEAU SORTI OFFICIELLEMENT
│
├── 1. ŒUVRE MUSICALE
│   ├── Ce que c’est : composition, mélodie, harmonie, paroles éventuelles
│   ├── Personnes concernées : auteurs, compositeurs, éditeurs
│   ├── Organisme typique en France : SACEM
│   └── Document utile : split sheet auteur/compositeur
│
├── 2. MASTER / ENREGISTREMENT
│   ├── Ce que c’est : fichier final exploité, version distribuée, phonogramme
│   ├── Personnes concernées : producteur phonographique, propriétaire ou exploitant du master
│   ├── Organismes typiques en France : SCPP ou SPPF
│   └── Données utiles : ISRC, distributeur, contrat master, date de sortie
│
└── 3. INTERPRÉTATION
    ├── Ce que c’est : voix, performance, instrument joué, interprétation enregistrée
    ├── Personnes concernées : chanteur, rappeur, musicien, interprète
    ├── Organismes typiques en France : ADAMI ou SPEDIDAM
    └── Documents utiles : feuille de présence, contrat artiste, crédits
```

### Lecture rapide

| Couche | Question simple | Document minimum | Organisme à étudier |
| --- | --- | --- | --- |
| Œuvre | Qui a écrit ou composé ? | Split sheet | SACEM |
| Master | Qui produit ou exploite l’enregistrement ? | Contrat master + ISRC | SCPP / SPPF |
| Interprétation | Qui chante, rappe ou joue ? | Contrat / feuille de présence | ADAMI / SPEDIDAM |

### Exemple concret

Vous créez le beat. Un rappeur écrit et enregistre sa voix. Vous financez aussi le mix, l’artwork et la distribution du morceau.

Dans ce cas, vous pouvez être concerné par plusieurs couches :

* comme compositeur, pour la partie musicale ;
* comme éventuel producteur phonographique, si vous produisez et exploitez réellement le master ;
* le rappeur peut être auteur et artiste-interprète ;
* le distributeur peut créer ou gérer l’ISRC ;
* les organismes concernés ne seront pas les mêmes selon le rôle exact de chacun.

**À retenir :** avant de demander “qui me paie ?”, demandez “sur quelle couche suis-je réellement présent ?”.

## 6.2 Samples : le terrain miné

Un sample est un extrait sonore existant réutilisé dans une nouvelle création.

Si vous utilisez un sample protégé sans autorisation, le problème ne disparaît pas parce que le beat est bon.

### Questions à poser

* Le sample vient-il d’une œuvre protégée ?
* Ai-je une licence claire ?
* Le pack de samples autorise-t-il l’usage commercial ?
* Dois-je créditer quelqu’un ?
* Puis-je vendre une exclusive avec ce sample ?
* Puis-je utiliser ce sample en sync, publicité ou jeu vidéo ?

**Erreur à éviter :** croire que “personne ne reconnaîtra” est une stratégie juridique. Ce n’est pas une stratégie. C’est un pari.

## 6.3 Split sheet : le document qui sauve les relations

Une split sheet indique la répartition des droits entre les contributeurs.

Elle doit être faite quand plusieurs personnes participent à une œuvre : beatmaker, topliner, chanteur, rappeur, guitariste, co-producteur, arrangeur.

### Exemple simple

| Personne  | Rôle           | Pourcentage |
| --------- | -------------- | ----------: |
| Beatmaker | Instrumentale  |        50 % |
| Artiste   | Texte + voix   |        40 % |
| Topliner  | Mélodie vocale |        10 % |

Ce tableau doit être discuté avant la sortie. Pas après les premiers streams.

## 6.4 IA : assistant, pas zone grise

L’IA peut vous aider à créer des idées, organiser votre catalogue, écrire des descriptions, générer des variantes ou préparer des messages.

Mais vous devez rester prudent sur :

* l’origine des sons générés ;
* les droits d’utilisation des outils ;
* les données envoyées dans les plateformes ;
* l’utilisation de voix, styles ou références trop proches d’artistes existants ;
* l’entraînement d’IA avec vos propres fichiers ou ceux de clients.

### Clause simple à intégrer

> Le licencié n’est pas autorisé à utiliser le beat, les stems ou tout élément livré pour entraîner un modèle d’intelligence artificielle, créer une imitation de l’œuvre ou générer des œuvres dérivées automatisées sans accord écrit du beatmaker.

Ce n’est pas une clause magique. Mais elle pose un cadre.

## 6.5 Preuves et archives

Gardez :

* fichiers projet ;
* exports datés ;
* emails ;
* contrats ;
* factures ;
* preuves de paiement ;
* versions livrées ;
* messages importants ;
* captures si nécessaire.

Un dossier bien archivé ne garantit pas que vous gagnerez un litige. Mais un dossier vide vous met déjà en faiblesse.

## Encadré Camille — Protection sans surcharge

Camille, cette partie peut te donner l’impression qu’il faut devenir juriste, comptable et manager en même temps. Ce n’est pas le but.

Tu dois seulement créer trois réflexes : garder une trace, écrire les pourcentages, ne pas livrer dans le flou.

Quand tu es fatiguée, ne cherche pas à tout sécuriser. Sécurise le prochain échange important. Un contrat simple aujourd’hui vaut mieux qu’un système parfait jamais envoyé.

**Phrase à retenir :** je ne protège pas mon travail pour durcir mon activité. Je le protège pour respirer.

## 6.6 Content ID — Ce que vous devez savoir avant qu’un artiste ne dépose votre beat

### Le problème

Content ID est un système utilisé par YouTube et d’autres plateformes pour identifier et monétiser les musiques protégées par des droits d’auteur.

Quand un artiste dépose un morceau sur lequel il a posé sa voix sur votre beat, il peut techniquement revendiquer le beat ou une partie de l’instrumental dans un système Content ID.

Si cela arrive sans votre accord, vous pouvez :

* ne plus pouvoir utiliser votre propre beat sur YouTube ;
* voir des revenus redirigés vers l’artiste ;
* recevoir des réclamations sur vos propres contenus ;
* devoir engager une procédure pour faire valoir vos droits.

Le Content ID n’est pas mauvais en soi. Le problème, c’est le dépôt sans cadre.

### Ce que vous devez faire avant

1. **Écrivez une clause Content ID dans votre licence.**

> L’artiste n’est pas autorisé à déposer le beat seul, les stems ou tout élément de l’instrumental dans un système Content ID, YouTube, Facebook, TikTok ou autre, sans autorisation écrite du beatmaker. Le morceau final peut être déposé, mais le beatmaker doit être crédité et les droits sur l’instrumental doivent rester clairs.

2. **Prévenez l’artiste à l’oral et par écrit.**

Beaucoup d’artistes ne savent pas qu’un dépôt Content ID peut bloquer l’exploitation du beat. Une explication simple évite souvent un conflit.

3. **Gardez vos preuves.**

Contrat, échanges, fichiers datés, projet DAW, exports, split sheet. Sans preuve, vous discutez dans le brouillard.

### Que faire si un artiste dépose votre beat sans accord ?

1. **Contactez l’artiste.** Expliquez le problème et montrez votre contrat. Parfois, c’est une erreur de bonne foi.

2. **Si l’artiste ne répond pas, utilisez les procédures de contestation de la plateforme.** Préparez vos preuves avant d’ouvrir le litige.

3. **Si le litige persiste, consultez un avocat spécialisé.** Une mise en demeure peut suffire, mais ne menacez pas à l’aveugle.

**À retenir :** le Content ID n’est pas l’ennemi. L’ennemi, c’est l’absence d’accord clair. Une clause simple dans votre licence protège tout le monde.

## 6.7 Le beatmaker qui distribue : ISRC, UPC, ISWC et métadonnées

### Le problème

Quand vous vendez un beat, vous pensez souvent au fichier : MP3, WAV, stems. Mais dès qu’un morceau sort officiellement, les plateformes et les sociétés de gestion ne raisonnent pas seulement en fichiers. Elles raisonnent en identifiants.

Un identifiant permet de suivre un enregistrement, un produit, une œuvre ou une exploitation. Sans identifiant fiable, vous pouvez perdre la trace d’un titre.

### Les identifiants à comprendre

| Code | Ce qu’il identifie | Exemple d’usage |
| --- | --- | --- |
| ISRC | Un enregistrement précis | Le master d’un morceau, une version radio, une version live |
| UPC / EAN | Un produit ou une sortie | Un single, EP ou album distribué |
| ISWC | Une œuvre musicale | La composition déclarée auprès d’une société d’auteurs |
| IPI | Une personne ou entité ayant droit | Auteur, compositeur, éditeur |
| ID3 | Métadonnées dans certains fichiers audio | Titre, artiste, album, année, genre |
| BWF / iXML | Métadonnées audio professionnelles | Fichiers de production, broadcast, sync |

### ISRC : le code de l’enregistrement

L’ISRC suit un enregistrement, pas “la chanson” au sens large. Une version différente peut nécessiter un ISRC différent : version radio, remix, live, instrumental, remaster.

Si vous êtes seulement beatmaker et que l’artiste distribue le morceau final, c’est souvent le distributeur ou le producteur du master qui fournit ou attribue l’ISRC. Mais vous devez demander l’information et la noter.

### UPC : le code de la sortie

L’UPC identifie le produit distribué : single, EP, album. Il sert surtout à la distribution commerciale.

### ISWC : le code de l’œuvre

L’ISWC concerne l’œuvre musicale : composition, texte, musique. Il peut apparaître après déclaration auprès d’une société d’auteurs selon les processus applicables. Ne le confondez pas avec l’ISRC.

### Tableau simple

| Situation | À demander |
| --- | --- |
| Vous vendez une licence simple sans sortie officielle connue | Contrat, paiement, fichiers livrés, crédit |
| L’artiste sort le morceau sur plateformes | ISRC, distributeur, date de sortie, crédits, split sheet |
| Vous distribuez votre propre projet instrumental | ISRC, UPC, métadonnées, distributeur, propriétaire du master |
| Une collaboration sort sous nom commun | Contrat de collaboration, split sheet, ISRC, rôles exacts |
| Placement sync ou média | ISRC, stems, metadata, contact droits, absence de samples risqués |

### Métadonnées minimales à conserver

Pour chaque morceau officiellement exploité, notez :

* titre exact ;
* artistes ;
* beatmaker / producteur ;
* auteurs et compositeurs ;
* ISRC ;
* UPC si disponible ;
* distributeur ;
* date de sortie ;
* lien Spotify / Apple / Deezer / YouTube ;
* statut du master ;
* société de gestion concernée ;
* contrat ou licence associée ;
* split sheet.

### Erreur à éviter

Ne demandez pas l’ISRC six mois après la sortie. Demandez-le dès que l’artiste vous annonce une distribution officielle.

**Phrase type :**

> Pour mon suivi catalogue et mes droits, peux-tu me transmettre l’ISRC du morceau, le nom du distributeur, la date de sortie officielle et les crédits utilisés ? Merci, ça me permet d’archiver proprement la collaboration.

## 6.8 Contrat de featuring et collaboration

### Le problème

Une collaboration n’est pas une simple vente. Si vous créez un morceau avec un artiste, un topliner, un chanteur ou un autre producteur, vous n’êtes plus seulement dans une logique “client achète beat”. Vous êtes dans une œuvre commune.

Il faut donc distinguer :

* licence de beat ;
* collaboration artistique ;
* featuring ;
* co-production ;
* arrangement ;
* topline ;
* production du master.

### Licence ou collaboration ?

| Situation | Document recommandé |
| --- | --- |
| L’artiste achète un beat existant | Licence de beat |
| Vous créez ensemble une œuvre nouvelle | Contrat de collaboration + split sheet |
| Un artiste pose gratuitement pour exposition | Accord de featuring écrit |
| Un artiste est payé pour poser | Contrat de prestation / cession ou autorisation adaptée |
| Deux producteurs créent une prod ensemble | Split sheet producteur + accord sur l’exploitation |
| Vous financez l’enregistrement final | Accord sur le master et le producteur phonographique |

### Les points à écrire

Un contrat de collaboration doit préciser :

* qui participe ;
* qui fait quoi ;
* qui possède quelle part de composition ;
* qui possède ou exploite le master ;
* qui paie les frais ;
* qui distribue ;
* qui choisit le distributeur ;
* qui reçoit les revenus ;
* comment les revenus sont répartis ;
* qui peut signer une synchro ;
* qui peut retirer le morceau ;
* comment les crédits seront affichés ;
* quelles limites existent pour l’IA, les samples, le Content ID.

### Featuring gratuit ou payant

Un featuring “gratuit” doit quand même être écrit. Gratuit ne veut pas dire sans droits. L’artiste qui pose une voix peut avoir des droits d’interprète et parfois des droits d’auteur si sa contribution est originale.

Si le featuring est payé, le contrat doit préciser si le paiement couvre seulement la session, une prestation, une autorisation d’exploitation, une cession particulière, ou une combinaison de ces éléments.

### Modèle court de clause

> Les parties reconnaissent que le morceau intitulé provisoirement “[Titre]” est une collaboration. Les contributions, crédits, pourcentages de composition, conditions d’exploitation du master et modalités de répartition des revenus sont définis dans la split sheet et le tableau financier annexés au présent accord.

**À retenir :** une collaboration sans écrit peut devenir plus dangereuse qu’une vente sans contrat, car chacun peut penser avoir “fait le morceau”.

## 6.9 Sociétés de gestion collective : France et international

### Pourquoi cette partie compte

Un beatmaker indépendant peut être concerné par plusieurs familles de droits :

* les droits d’auteur sur la composition ;
* les droits voisins du producteur phonographique ;
* les droits voisins des artistes-interprètes ;
* les revenus liés au master ;
* les revenus de distribution ;
* la rémunération équitable ou copie privée selon les pays et exploitations.

Le piège est de tout appeler “royalties”. Ce mot est trop large. Il faut savoir de quelle couche on parle.

### France : repères simples

| Organisme | Profil principalement concerné | À comprendre |
| --- | --- | --- |
| SACEM | auteurs, compositeurs, éditeurs | droits d’auteur liés aux œuvres |
| SCPP / SPPF | producteurs phonographiques | droits voisins des producteurs |
| ADAMI / SPEDIDAM | artistes-interprètes | droits voisins des interprètes |
| SAI | artistes-interprètes concernés par certains droits spécifiques | rémunération annuelle supplémentaire selon conditions |
| SPRÉ | dispositif de rémunération équitable | collecte/répartition via organismes concernés |

### SCPP ou SPPF ?

La SCPP et la SPPF concernent les producteurs phonographiques. En simplifiant : si vous êtes producteur du master, que vous exploitez des enregistrements et que vous remplissez les conditions d’admission, vous pouvez vous renseigner auprès de l’une d’elles. Le choix dépend du profil, du catalogue, des conditions d’adhésion, des répertoires représentés et des services.

Un beatmaker qui vend seulement des licences de beats n’est pas automatiquement producteur phonographique du morceau final. Il peut le devenir si les contrats et la réalité économique le placent dans ce rôle : financement, fixation, exploitation, distribution du master.

### ADAMI ou SPEDIDAM ?

L’ADAMI et la SPEDIDAM concernent les artistes-interprètes. Si vous êtes uniquement beatmaker instrumental sans interprétation enregistrée, ce n’est pas forcément votre porte d’entrée. Si vous jouez, chantez, rappez, interprétez ou apparaissez comme artiste sur un enregistrement, la question devient pertinente.

### SAI

La SAI est liée à une rémunération annuelle supplémentaire de 20 % dans certains cas concernant les artistes-interprètes et l’allongement de la durée des droits. Ce n’est pas un guichet magique pour tout beatmaker. C’est un sujet à comprendre selon votre statut réel d’interprète et les enregistrements concernés.

### International : le réflexe CMO

CMO signifie Collective Management Organization : organisme de gestion collective.

Exemples à connaître :

| Pays / zone | Organisme cité | Profil général |
| --- | --- | --- |
| États-Unis | SoundExchange | droits voisins / digital performance, artistes et ayants droit du master selon cas |
| Royaume-Uni | PPL | performers et recording rightsholders |
| Allemagne | GVL | artistes-interprètes et producteurs |
| Espagne | AIE / AGEDI | AIE pour interprètes, AGEDI pour producteurs |
| France | SCPP, SPPF, ADAMI, SPEDIDAM | producteurs et artistes-interprètes selon organisme |

### Le bon réflexe

Avant de vous affilier partout, posez trois questions :

1. Suis-je auteur-compositeur, artiste-interprète, producteur du master, ou seulement vendeur d’une licence ?
2. Dans quel pays le morceau est-il exploité ?
3. Qui déclare l’enregistrement et qui possède l’ISRC ?

### Cas pratique : récupérer la trace d’un morceau sorti

Vous avez vendu un beat. L’artiste a sorti le titre. Vous n’avez rien noté.

Faites maintenant :

1. Demander le lien officiel de sortie.
2. Demander l’ISRC.
3. Demander le distributeur.
4. Vérifier les crédits.
5. Retrouver la licence ou le contrat.
6. Vérifier si une split sheet existe.
7. Identifier votre rôle réel : compositeur, beatmaker licencié, coproducteur, producteur du master, interprète.
8. Selon ce rôle, contacter l’organisme adapté ou demander conseil.

### Message type

> Salut [Prénom], je mets à jour mon catalogue et mes archives. Pour le morceau [titre], peux-tu me confirmer l’ISRC, le distributeur, la date de sortie, les crédits affichés et la répartition validée ? Ce n’est pas pour bloquer quoi que ce soit, c’est pour que tout soit propre côté droits, déclarations et suivi.

**À retenir :** ne commencez pas par “quelle société peut me payer ?”. Commencez par “quel est mon rôle exact sur cet enregistrement ?”.

## 6.10 Checklist — Avant de signer avec un label

Recevoir une proposition de label peut flatter l’ego. Mais une offre sérieuse doit être lue froidement. Un label peut apporter de la distribution, de la crédibilité, du budget, du réseau, de la promotion et du suivi. Il peut aussi bloquer un catalogue si le contrat est mal compris.

Cette checklist ne remplace pas un avocat. Elle sert à repérer les points à vérifier avant de signer.

### 1. Identité de l’offre

* [ ] Le nom exact du label est écrit.
* [ ] La société juridique derrière le label est identifiée.
* [ ] Le pays et l’adresse de la structure sont connus.
* [ ] La personne qui vous contacte a le pouvoir de proposer un contrat.
* [ ] Vous avez vérifié les sorties précédentes du label.

### 2. Droits demandés

* [ ] Le contrat dit clairement s’il concerne l’œuvre, le master, la distribution, l’édition ou plusieurs couches.
* [ ] La durée de l’engagement est écrite.
* [ ] Le territoire est écrit : France, Europe, monde entier.
* [ ] L’exclusivité est claire : exclusive ou non exclusive.
* [ ] Les morceaux concernés sont listés précisément.
* [ ] Le label ne prend pas automatiquement tout votre futur catalogue sans limite.

### 3. Argent et revenus

* [ ] L’avance éventuelle est écrite.
* [ ] Le pourcentage de royalties est écrit.
* [ ] Les frais récupérables par le label sont listés.
* [ ] La fréquence des relevés de compte est indiquée.
* [ ] Le délai de paiement est indiqué.
* [ ] Les commissions du distributeur ou des intermédiaires sont compréhensibles.

### 4. Master et ISRC

* [ ] Qui possède le master est écrit.
* [ ] Qui distribue est écrit.
* [ ] Qui crée ou fournit l’ISRC est écrit.
* [ ] Qui peut retirer le morceau des plateformes est écrit.
* [ ] Qui peut autoriser une synchro est écrit.
* [ ] Les crédits du beatmaker sont écrits.

### 5. Promotion et obligations du label

* [ ] Le label précise ce qu’il fait concrètement : distribution, playlisting, clip, RP, ads, studio, mix, mastering.
* [ ] Les budgets annoncés sont écrits, pas seulement promis oralement.
* [ ] Les obligations de sortie sont claires.
* [ ] Le label ne peut pas garder votre musique bloquée sans la sortir pendant une durée abusive.

### 6. Sortie du contrat

* [ ] Il existe une clause de fin ou de résiliation.
* [ ] Vous savez ce qui arrive aux morceaux déjà sortis après la fin du contrat.
* [ ] Vous savez si les droits reviennent automatiquement ou non.
* [ ] Vous savez quoi faire en cas de non-paiement ou absence de reporting.

### 7. Phrase de prudence

Ne signez jamais le soir même parce qu’on vous met la pression. Une vraie opportunité peut attendre une relecture.

**Phrase type à envoyer :**

> Merci pour la proposition. Je suis intéressé, mais je souhaite prendre le temps de relire le contrat et de le faire vérifier avant de signer. Pouvez-vous me confirmer la durée, le territoire, les droits concernés, le pourcentage de royalties, les frais récupérables, le distributeur, l’ISRC et les obligations concrètes du label ?

**À retenir :** un label sérieux ne vous demande pas de signer dans la panique. Il accepte que vous compreniez ce que vous engagez.


## 6.11 Que faire si un label ne paie pas ?

### Le problème

Un label peut signer un contrat, sortir un morceau, promettre un paiement, puis payer en retard, envoyer un relevé incomplet ou ne plus répondre. C’est une situation fréquente, surtout quand les accords ont été signés vite, sans calendrier clair, sans reporting précis ou sans preuve de livraison.

Le danger est de réagir trop tard, trop violemment ou sans dossier. Vous devez avancer comme un professionnel : contrat, preuves, relances, mise en demeure si nécessaire, puis conseil juridique si le blocage continue.

Cette section ne remplace pas un avocat. Elle donne une méthode de survie pour ne pas rester bloqué dans le flou.

### Étape 1 — Relire le contrat avant d’accuser

Avant d’écrire au label, vérifiez exactement ce qui est prévu.

Cherchez dans le contrat :

* le montant dû ;
* la date ou le délai de paiement ;
* la fréquence des relevés de royalties ;
* la définition des revenus : brut, net, net receipts ;
* les frais récupérables ;
* les conditions de recoupement ;
* les seuils minimums de paiement ;
* les obligations de reporting ;
* la loi applicable et le tribunal compétent ;
* la clause de résiliation ;
* la clause de médiation ou règlement amiable éventuel.

**Erreur à éviter :** confondre “le label ne paie pas” et “le label considère que les revenus sont recoupés”. Le résultat est frustrant dans les deux cas, mais la réponse n’est pas la même.

### Étape 2 — Construire le dossier de preuves

Créez un dossier `LABEL_PAYMENT_ISSUE_[NOM_LABEL]`.

Mettez dedans :

* contrat signé ;
* avenants ;
* factures ;
* preuves de livraison des fichiers ;
* emails et messages importants ;
* captures de conversations ;
* liens de sortie officiels ;
* ISRC ;
* UPC ;
* relevés de royalties reçus ;
* preuves de streams ou exploitations visibles ;
* coordonnées juridiques du label ;
* historique des relances.

Votre force ne vient pas du ton. Elle vient de la clarté du dossier.

### Étape 3 — Envoyer une première relance simple

La première relance doit rester calme. L’objectif est d’obtenir une réponse, pas de déclencher une guerre.

**Modèle de relance simple :**

> Bonjour [Nom],  
> Je me permets de revenir vers vous au sujet du paiement / relevé lié à [titre du morceau], ISRC [code], sorti le [date].  
> Selon notre accord du [date du contrat], le paiement / reporting devait intervenir le [date ou période].  
> Pouvez-vous me confirmer la date de règlement prévue ou m’envoyer le relevé correspondant ?  
> Merci d’avance,  
> [Signature]

Gardez une trace de cette relance.

### Étape 4 — Envoyer une relance ferme avec délai

Si le label ne répond pas, envoyez une deuxième relance plus ferme, avec une date limite raisonnable.

**Modèle de relance ferme :**

> Bonjour [Nom],  
> Sauf erreur de ma part, je n’ai pas reçu de retour à ma relance concernant [titre], ISRC [code].  
> Je vous remercie de bien vouloir me transmettre le paiement / relevé attendu ou une explication écrite avant le [date].  
> Sans retour de votre part, je serai contraint de formaliser ma demande par courrier recommandé et de solliciter un conseil juridique.  
> Cordialement,  
> [Signature]

Le but n’est pas de menacer dans le vide. Le but est de montrer que vous suivez le dossier.

### Étape 5 — Préparer une mise en demeure

La mise en demeure est un courrier formel qui demande l’exécution d’une obligation : payer, transmettre un relevé, respecter un contrat, fournir des informations.

En France, elle peut être envoyée par lettre recommandée avec accusé de réception. Selon le montant, le pays, la loi applicable et la complexité du dossier, faites-vous aider par un avocat, une protection juridique ou une structure professionnelle.

**Une mise en demeure doit généralement contenir :**

* votre identité ;
* l’identité du label ;
* le contrat concerné ;
* le morceau concerné ;
* l’ISRC si disponible ;
* le montant ou document demandé ;
* les dates importantes ;
* le rappel des relances ;
* un délai clair pour régulariser ;
* la suite envisagée en cas d’absence de réponse.

**Phrase utile :**

> Je vous mets formellement en demeure de régulariser la situation sous [délai] à compter de la réception du présent courrier.

Ne rédigez pas une mise en demeure agressive ou approximative. Elle doit être claire, factuelle et exploitable.

### Étape 6 — Ne pas faire n’importe quoi publiquement

Quand un label ne paie pas, la tentation est forte de l’exposer sur les réseaux.

Soyez prudent.

Avant de publier :

* vérifiez que vous ne diffamez pas ;
* ne publiez pas de données privées ;
* ne menacez pas ;
* ne déformez pas les faits ;
* ne violez pas une clause de confidentialité ;
* demandez conseil si le contrat est important.

Un post de colère peut affaiblir votre dossier. Une trace écrite propre peut le renforcer.

### Étape 7 — Ne pas retirer un morceau sans comprendre vos droits

Ne faites pas retirer un morceau des plateformes sans vérifier :

* qui possède le master ;
* qui a le droit de demander le takedown ;
* ce que dit le contrat ;
* si le retrait peut vous exposer ;
* si d’autres ayants droit sont concernés.

Un takedown mal utilisé peut créer un conflit plus grave que le retard de paiement.

### Étape 8 — Passer au niveau supérieur

Si le label ne répond toujours pas, envisagez :

* protection juridique ;
* avocat spécialisé en musique ;
* médiation ;
* injonction de payer si le dossier s’y prête ;
* action judiciaire selon le montant et le contrat ;
* signalement à un distributeur ou partenaire si les conditions le permettent.

Les astreintes ne se décrètent pas dans un email. Elles peuvent être demandées dans certains cadres judiciaires, mais c’est un sujet à traiter avec un professionnel.

### Checklist impayé label

* [ ] J’ai relu le contrat.
* [ ] J’ai identifié la date ou période de paiement.
* [ ] J’ai vérifié les frais récupérables.
* [ ] J’ai demandé le relevé de royalties.
* [ ] J’ai créé un dossier de preuves.
* [ ] J’ai envoyé une relance simple.
* [ ] J’ai envoyé une relance ferme avec délai.
* [ ] J’ai préparé une mise en demeure si nécessaire.
* [ ] Je n’ai pas publié sous le coup de la colère.
* [ ] Je n’ai pas demandé de takedown sans conseil.
* [ ] J’ai envisagé protection juridique, avocat ou médiation.

**À retenir :** un impayé se traite avec un dossier, pas avec la rage. Votre objectif n’est pas d’avoir raison dans un DM. Votre objectif est d’obtenir paiement, reporting ou sortie propre du conflit.


## 6.12 Que faire si votre beat est utilisé sans licence ?

### Le problème

Un artiste utilise votre beat sans avoir acheté de licence, sans vous créditer, sans vous payer ou sans respecter les conditions prévues.

Cela peut arriver de plusieurs manières :

* il télécharge une preview YouTube et pose dessus ;
* il récupère un MP3 envoyé en privé ;
* il utilise un beat vendu en non-exclusif mais dépasse les droits autorisés ;
* il distribue le morceau sans split sheet ;
* il dépose le morceau dans Content ID alors que votre licence l’interdit ;
* il publie un clip, un freestyle ou une publicité avec votre instrumental sans accord.

La mauvaise réaction consiste à exploser en public sans dossier. La bonne réaction consiste à documenter, contacter, cadrer, puis escalader si nécessaire.

### Étape 1 — Ne pas paniquer, constater

Avant tout message, rassemblez les preuves.

À conserver immédiatement :

* lien YouTube, Spotify, TikTok, Instagram ou autre plateforme ;
* capture écran de la page ;
* date et heure de constat ;
* nom du compte ou de l’artiste ;
* titre du morceau ;
* description et crédits affichés ;
* extrait audio si possible ;
* lien vers votre beat original ;
* fichier projet ou export daté ;
* messages prouvant l’envoi ou l’absence de licence ;
* licence existante si elle a été dépassée.

**Règle simple :** pas de preuve, pas de force. Avant de parler, archivez.

### Étape 2 — Vérifier le scénario exact

Toutes les situations ne se traitent pas pareil.

| Situation | Réaction adaptée |
| --- | --- |
| L’artiste a oublié de payer mais reconnaît l’usage | régularisation + licence écrite |
| L’artiste a acheté une licence mais dépasse les limites | avenant, upgrade ou rappel contractuel |
| L’artiste utilise une preview sans autorisation | demande de retrait ou achat de licence |
| L’artiste monétise sans crédit ni contrat | relance ferme + preuve + délai |
| L’artiste dépose en Content ID sans accord | contestation + demande de retrait de la revendication |
| Usage publicitaire, marque ou sync non autorisé | ne pas gérer seul, demander conseil rapidement |

Ne criez pas “vol” trop vite si vous n’avez pas analysé le cas. Mais ne minimisez pas non plus une exploitation commerciale non autorisée.

### Étape 3 — Envoyer un premier message calme

Le premier message doit ouvrir une porte à la régularisation.

Exemple :

> Salut [Prénom], je viens de voir que le morceau [titre] utilise mon beat [nom du beat]. À ma connaissance, aucune licence n’a encore été validée pour cette exploitation. Peux-tu me confirmer la situation ? Si tu veux régulariser proprement, je peux t’envoyer la licence adaptée et les conditions correspondantes.

Ce message est utile car il est clair, non insultant, et laisse une solution.

### Étape 4 — Proposer une régularisation

Si l’artiste répond correctement, proposez :

* une licence standard ;
* une licence unlimited ;
* une upgrade si la licence initiale était trop limitée ;
* une split sheet ;
* un crédit correct ;
* une date limite de paiement ;
* un retrait si aucun accord n’est possible.

Ne laissez pas la régularisation dans le flou. Si vous acceptez que le morceau reste en ligne, écrivez les conditions.

### Étape 5 — Relance ferme si absence de réponse

Si l’artiste ignore votre message, envoyez une relance plus ferme.

Exemple :

> Bonjour [Prénom], je te relance au sujet du morceau [titre], qui utilise mon instrumental [nom du beat] sans licence validée à ma connaissance. Merci de régulariser la situation sous 7 jours : soit par achat de la licence adaptée, soit par retrait du morceau, soit par preuve d’un accord existant. Sans retour, je me réserve le droit d’utiliser les procédures de signalement et de faire valoir mes droits.

Gardez le ton professionnel. Une relance ferme n’a pas besoin d’être agressive.

### Étape 6 — Utiliser les plateformes avec prudence

Selon la plateforme, vous pouvez envisager :

* signalement YouTube ;
* contestation Content ID ;
* demande de retrait DMCA si la plateforme fonctionne avec ce système ;
* signalement auprès du distributeur ;
* contact avec l’agrégateur si vous l’identifiez ;
* demande de correction des crédits si le problème porte sur l’identification.

Mais attention : un signalement abusif ou mal fondé peut vous fragiliser. Vérifiez toujours ce que vous pouvez prouver.

### Étape 7 — Mise en demeure si nécessaire

Si l’exploitation est sérieuse, monétisée, répétée ou ignorée, préparez une mise en demeure.

Elle doit rappeler :

* votre identité ;
* le beat concerné ;
* les preuves ;
* l’usage constaté ;
* l’absence de licence ou le dépassement de licence ;
* ce que vous demandez : paiement, retrait, crédit, régularisation, relevé ;
* le délai ;
* les suites possibles.

Utilisez l’Annexe W comme trame, puis faites relire si le montant ou l’enjeu est important.

### Étape 8 — Quand demander conseil

Demandez conseil rapidement si :

* le morceau fait beaucoup de vues ou de streams ;
* une marque utilise le beat ;
* le morceau est distribué par un label ;
* l’artiste vous menace ;
* une plateforme bloque vos propres contenus ;
* le contrat est ambigu ;
* il y a plusieurs ayants droit ;
* il y a un sample dans votre beat ;
* l’usage concerne une publicité, un film, une série ou un jeu vidéo.

### Checklist utilisation sans licence

* [ ] J’ai gardé les liens.
* [ ] J’ai fait des captures.
* [ ] J’ai identifié la plateforme.
* [ ] J’ai retrouvé mon fichier original.
* [ ] J’ai retrouvé les messages d’envoi.
* [ ] J’ai vérifié s’il existe une licence.
* [ ] J’ai vérifié si la licence a été dépassée.
* [ ] J’ai envoyé un premier message calme.
* [ ] J’ai proposé une régularisation écrite.
* [ ] J’ai envoyé une relance ferme si nécessaire.
* [ ] J’ai envisagé plateforme, distributeur, mise en demeure ou avocat selon le niveau d’enjeu.

**À retenir :** l’objectif n’est pas de gagner une dispute en ligne. L’objectif est de régulariser, faire retirer ou protéger votre travail avec un dossier solide.

## 6.13 Que faire si vous êtes victime de phishing ou d’arnaque music business ?

### Le problème

Plus votre activité devient visible, plus vous pouvez recevoir des propositions qui ressemblent à des opportunités : faux label, faux manager, faux superviseur sync, faux concours de beatmaking, faux distributeur, faux placement, faux mail de plateforme, faux support technique.

L’arnaque ne commence pas toujours avec un message grossier. Parfois, elle commence avec une flatterie crédible :

> “Nous avons écouté votre catalogue. Un artiste signé cherche exactement ce style. Envoyez vos stems et payez les frais de dossier.”

Ou :

> “Votre morceau a été sélectionné pour une playlist officielle. Connectez-vous ici pour valider vos royalties.”

Le piège, c’est l’urgence. Plus on vous pousse à cliquer vite, payer vite, signer vite ou envoyer des fichiers vite, plus vous devez ralentir.

### Les signaux d’alerte

Méfiez-vous si :

* l’adresse email ne correspond pas au vrai domaine du label ;
* le message contient un lien raccourci ou suspect ;
* on vous demande un mot de passe ;
* on vous demande de payer pour débloquer un placement ;
* on vous promet une signature sans avoir parlé de contrat ;
* on vous demande les stems avant tout accord ;
* on vous demande une copie de pièce d’identité sans cadre clair ;
* on refuse de vous donner un nom complet, une société, un numéro d’enregistrement ou un site officiel ;
* on vous presse avec une fausse urgence ;
* le contrat contient des fautes, des incohérences ou un nom de société différent ;
* on vous demande de signer dans une langue que vous ne comprenez pas.

### Les 8 réflexes avant de répondre

1. **Ne cliquez pas immédiatement.**
   Ouvrez le site officiel du label par vous-même, pas depuis le lien reçu.

2. **Vérifiez l’email.**
   Un vrai label utilise généralement un domaine officiel. Méfiez-vous des adresses gratuites ou des domaines presque identiques.

3. **Cherchez la personne.**
   Vérifiez LinkedIn, site officiel, crédits publics, Discogs, répertoire professionnel, mentions légales.

4. **Demandez une confirmation par canal officiel.**
   Écrivez au contact indiqué sur le site officiel.

5. **Ne payez aucun frais de dossier suspect.**
   Un vrai deal ne commence pas par “payez pour être signé”.

6. **N’envoyez pas les stems sans accord.**
   Envoyez une preview taggée ou un lien privé, pas un dossier complet exploitable.

7. **Archivez tout.**
   Capturez les messages, emails, liens, domaines, profils, documents reçus.

8. **Demandez un avis extérieur.**
   Avant signature ou paiement, faites relire par une personne compétente.

### Que faire si vous avez cliqué ou répondu ?

Si vous avez seulement répondu sans envoyer d’information sensible, arrêtez l’échange, archivez, puis vérifiez l’identité.

Si vous avez envoyé un mot de passe, changez-le immédiatement, activez la double authentification et vérifiez les connexions récentes.

Si vous avez envoyé des informations bancaires, contactez votre banque rapidement.

Si vous avez payé, récupérez les preuves, contactez le service de paiement et envisagez un signalement.

Si vous avez envoyé des stems ou fichiers exploitables, créez un dossier de preuves et surveillez les plateformes.

### Message de vérification simple

> Bonjour,
>
> Merci pour votre message. Avant d’aller plus loin, pouvez-vous me confirmer votre identité complète, votre fonction, le site officiel de votre structure, le nom de la société contractante et l’adresse email professionnelle depuis laquelle nous poursuivrons l’échange ?
>
> Par sécurité, je ne transmets ni stems, ni documents sensibles, ni paiement avant vérification complète.

### Message si le doute est sérieux

> Bonjour,
>
> Après vérification, je ne suis pas en mesure de confirmer l’authenticité de votre demande. Je ne donnerai donc pas suite pour le moment. Merci de ne plus utiliser mes contenus, fichiers ou informations sans accord écrit.

### À retenir

Un vrai professionnel accepte la vérification. Un arnaqueur insiste sur l’urgence.

Votre protection commence par une règle simple : ne jamais laisser l’ego signer à la place du cerveau.


## 6.14 Que faire si votre beat est utilisé par une marque sans autorisation ?

### Le problème

Une marque, une agence, un média, un créateur sponsorisé ou une entreprise peut utiliser votre beat dans une publicité, une vidéo promotionnelle, un réel sponsorisé, un film de marque, un événement, une campagne TikTok, une vidéo YouTube monétisée ou un contenu corporate.

Ce n’est pas la même chose qu’un rappeur qui pose sur un beat sans licence.

Quand une marque utilise une musique, on parle souvent d’un usage de synchronisation ou d’un usage commercial associé à une image, un produit, un service ou une campagne. La valeur peut être beaucoup plus élevée qu’une licence beat classique.

Le danger : réagir sous le coup de la colère, supprimer vos preuves, envoyer un message agressif, ou accepter une petite somme sans comprendre ce que la marque a réellement exploité.

### Première règle : ne commencez pas par accuser

Commencez par documenter.

Avant tout message, créez un dossier :

`BRAND_UNAUTHORIZED_USE`

À l’intérieur :

* captures d’écran datées ;
* lien URL de la publication ;
* nom de la marque ;
* nom de l’agence si connue ;
* date de découverte ;
* plateforme concernée ;
* durée de la vidéo ;
* passage exact où le beat est utilisé ;
* preuve que le beat vient de vous ;
* fichier projet ou export d’origine ;
* licence existante ou absence de licence ;
* captures des vues, likes, publicités ou sponsorisations si visibles.

### Ce qu’il faut vérifier

Posez-vous ces questions :

1. Est-ce bien mon beat ?
2. Est-ce une version exacte, modifiée, samplée ou réinterprétée ?
3. La marque a-t-elle acheté une licence via une plateforme ?
4. Un artiste ou client a-t-il transmis le beat à la marque ?
5. Une licence existante autorisait-elle la publicité ou la synchronisation ?
6. Le contenu est-il organique, sponsorisé ou publicitaire ?
7. La vidéo est-elle encore en ligne ?
8. La campagne semble-t-elle locale, nationale ou internationale ?
9. L’usage concerne-t-il seulement un post ou une campagne complète ?
10. Ai-je les preuves suffisantes avant de contacter quelqu’un ?

### Message de premier contact à une marque

> Bonjour,
>
> Je vous contacte au sujet de la vidéo publiée le [date] sur [plateforme/lien], dans laquelle semble être utilisée une instrumentale dont je suis le créateur.
>
> À ce stade, je souhaite simplement clarifier la situation : pouvez-vous me confirmer l’origine de la musique utilisée, le cadre de la licence obtenue, la durée de la campagne et l’agence ou personne responsable du choix musical ?
>
> Merci de votre retour afin que nous puissions régulariser proprement si nécessaire.

Ce message est volontairement calme. Il ouvre une porte. Il évite de transformer immédiatement le dossier en conflit.

### Si la marque répond positivement

Demandez :

* le nom de la société contractante ;
* le périmètre d’usage ;
* la durée de la campagne ;
* les territoires ;
* les plateformes ;
* le budget média si pertinent ;
* l’agence responsable ;
* la preuve de licence si elle existe ;
* la proposition de régularisation.

Ensuite, ne vendez pas une “licence beat standard” si l’usage est publicitaire. Une marque qui utilise une musique pour vendre un produit n’est pas dans le même cadre qu’un artiste indépendant qui sort un morceau.

### Si la marque ne répond pas

Procédez par étapes :

1. relance courte après quelques jours ;
2. deuxième relance plus ferme ;
3. mise en demeure si l’usage continue ou si le préjudice semble réel ;
4. signalement plateforme si nécessaire ;
5. consultation d’un avocat spécialisé si la marque est identifiable, solvable et que l’usage est significatif.

### Message de relance ferme

> Bonjour,
>
> Je vous relance concernant l’utilisation de mon instrumental dans votre contenu publié le [date] à l’adresse suivante : [lien].
>
> Sauf erreur de ma part, je n’ai pas retrouvé d’autorisation écrite couvrant cet usage commercial.
>
> Merci de me transmettre sous 7 jours les éléments de licence ou de me proposer une régularisation écrite. À défaut, je me réserve la possibilité de faire constater l’usage et de demander conseil pour la suite.

### Plateformes et retrait

Selon la plateforme, vous pouvez signaler une atteinte aux droits. Mais réfléchissez avant de demander un retrait immédiat.

Dans certains cas, une régularisation financière est préférable à un retrait brutal. Dans d’autres cas, si la marque refuse ou si l’usage nuit à votre image, le retrait peut être prioritaire.

### À ne pas faire

* insulter publiquement la marque avant d’avoir vérifié ;
* supprimer vos propres fichiers ou messages ;
* envoyer des stems pour “prouver” trop vite ;
* accepter un paiement sans document écrit ;
* céder tous vos droits pour une régularisation minime ;
* confondre licence artiste et licence publicitaire ;
* signer un accord rétroactif sans lire les droits cédés.

### À retenir

Une utilisation par une marque peut être une violation, mais aussi une opportunité de régularisation sérieuse.

Votre force vient de trois choses : preuves, calme, cadre écrit.



## 6.15 Que faire si votre beat est utilisé par une IA générative ?

### Le problème

Un beat peut aujourd’hui être utilisé comme matière première dans un workflow d’intelligence artificielle : génération de voix, imitation de style, création de mélodies dérivées, séparation de stems, entraînement de modèle, génération de variantes, remix automatisé ou création de contenus publicitaires à partir d’éléments existants.

Le danger n’est pas seulement qu’un outil “s’inspire” de votre travail. Le danger est que vos fichiers, vos stems ou votre identité sonore soient intégrés dans un système que vous ne contrôlez plus, puis réutilisés dans des morceaux, vidéos, campagnes ou banques de sons sans cadre clair.

Cette situation est encore mouvante juridiquement. Vous devez donc raisonner de manière pratique : preuve, contrat, interdiction écrite, traçabilité, demande d’explication, puis conseil professionnel si l’enjeu devient important.

### Les cas fréquents

| Situation | Risque principal | Réflexe immédiat |
| --- | --- | --- |
| Un artiste utilise vos stems pour générer des variantes IA | perte de contrôle sur les dérivés | vérifier la licence et demander l’arrêt ou la régularisation |
| Un label entraîne un outil interne avec vos beats | exploitation non prévue | demander le fondement contractuel écrit |
| Une voix IA est posée sur votre beat sans accord | sortie non cadrée | exiger crédits, contrat, splits et limites d’usage |
| Un beat généré ressemble fortement à votre production | preuve difficile | archiver comparaisons, dates, fichiers et échanges |
| Une marque crée une musique IA à partir de votre beat | usage commercial non autorisé | traiter comme usage de marque + usage IA |

### Première règle : ne livrez jamais les stems sans clause IA

Vos stems ont beaucoup plus de valeur qu’un simple MP3 preview. Ils permettent de reconstruire, modifier, analyser et réutiliser votre production.

Avant de livrer des stems, ajoutez une clause simple :

> Les fichiers livrés, y compris le beat, les stems, exports séparés, fichiers MIDI, presets, voix témoins ou éléments de session, ne peuvent pas être utilisés pour entraîner, affiner, alimenter ou générer un modèle d’intelligence artificielle, ni pour produire des œuvres dérivées automatisées, sans autorisation écrite préalable du beatmaker.

Cette clause ne règle pas tout. Mais elle donne un point d’appui.

### Créer un dossier de preuves

Si vous suspectez une utilisation IA non autorisée, créez un dossier :

`AI_UNAUTHORIZED_USE`

À l’intérieur :

* votre fichier original ;
* projet DAW ou export daté ;
* stems éventuellement livrés ;
* contrat ou licence envoyée ;
* messages où les fichiers ont été transmis ;
* lien du morceau ou contenu suspect ;
* captures d’écran datées ;
* comparaison audio si possible ;
* description précise des ressemblances ;
* nom de l’outil IA si connu ;
* identité de l’artiste, label, marque ou créateur concerné ;
* preuve d’exploitation commerciale si elle existe.

### Message de clarification

> Salut [Prénom],
>
> J’ai découvert [morceau / contenu / lien] et plusieurs éléments semblent provenir de mon beat ou de fichiers que je t’ai transmis.
>
> Peux-tu me confirmer si le beat, les stems ou tout élément livré ont été utilisés dans un outil d’intelligence artificielle, pour générer une voix, une variation, un remix, une mélodie ou un contenu dérivé ?
>
> Je te rappelle que je n’ai pas autorisé l’utilisation de mes fichiers pour entraîner ou alimenter un système IA sans accord écrit. Je souhaite clarifier ça proprement avant d’aller plus loin.

### Si l’usage IA est confirmé

Demandez :

* quel outil a été utilisé ;
* quels fichiers ont été importés ;
* si les fichiers ont servi à entraîner un modèle ou seulement à générer un rendu ponctuel ;
* qui possède le résultat généré ;
* si le morceau est distribué ;
* quel ISRC a été attribué ;
* quels crédits apparaissent ;
* si une exploitation commerciale existe ;
* si les fichiers peuvent être supprimés de l’outil ou du compte utilisé ;
* quelle régularisation est proposée.

### Si la personne refuse de répondre

Procédez par étapes :

1. relance écrite courte ;
2. demande de retrait ou suspension de l’exploitation ;
3. signalement plateforme si le contenu est publié ;
4. mise en demeure si l’usage est sérieux ;
5. consultation d’un avocat spécialisé si l’exploitation est significative.

### Ce qu’il ne faut pas faire

* accuser sans preuve minimale ;
* publier immédiatement une dénonciation publique ;
* envoyer d’autres stems “pour comparer” ;
* accepter une sortie officielle sans clarifier les droits ;
* signer une régularisation qui autorise rétroactivement tous les usages IA ;
* confondre “voix IA posée sur mon beat” et “entraînement d’un modèle avec mes fichiers” ;
* croire qu’un outil IA rend automatiquement l’usage légal.

### À retenir

L’IA ne supprime pas le besoin de contrat. Elle le rend plus urgent.

Votre protection commence avant le problème : clauses IA, preuves datées, livraison limitée des stems et refus clair de l’entraînement non autorisé.

## 6.16 Que faire si un autre beatmaker sample votre beat sans autorisation ?

### Le problème

Un artiste qui pose sur votre beat sans licence est un cas. Un autre beatmaker qui réutilise votre boucle, votre mélodie, votre riff, votre enregistrement ou une partie reconnaissable de votre production en est un autre.

Dans ce cas, la question n’est pas seulement : “A-t-il utilisé mon beat ?” La vraie question est : “Qu’a-t-il repris exactement, et cette reprise crée-t-elle une exploitation commerciale identifiable ?”

### Ce qu’il faut distinguer

| Situation | Réflexe |
| --- | --- |
| Il a repris une idée générale de style | Difficile à contester : un style seul se protège mal |
| Il a repris une boucle audio reconnaissable | Documenter l’usage et demander régularisation |
| Il a repris une mélodie identifiable | Vérifier composition, preuve de création et exploitation |
| Il a repris un stem ou un export complet | Agir rapidement : preuve, contact, retrait ou licence |
| Il a revendu une production basée sur votre beat | Demander retrait, régularisation ou accord écrit |

### Première réponse recommandée

Ne partez pas directement en guerre. Commencez par constituer un dossier :

* lien vers le morceau ou beat concerné ;
* date de découverte ;
* capture écran ;
* téléchargement légal ou enregistrement de preuve si possible ;
* votre fichier original daté ;
* projet DAW ou export antérieur ;
* preuves de publication ou d’envoi ;
* comparaison claire entre les deux versions.

### Message type

> Bonjour [Nom], j’ai constaté que votre production [titre/lien] semble reprendre un élément identifiable de mon beat [titre/lien], notamment [boucle/mélodie/stem]. Je préfère clarifier cela proprement avant toute escalade. Pouvez-vous me confirmer l’origine de cet élément et me dire si vous disposez d’une autorisation écrite ? Selon la situation, nous pouvons envisager une régularisation, un crédit, une licence ou un retrait.

### Régularisation possible

Selon le cas, vous pouvez demander :

* un retrait ;
* un crédit ;
* une licence rétroactive ;
* une split sheet ;
* un paiement forfaitaire ;
* une interdiction de réutilisation ;
* une clarification écrite pour les futures exploitations.

### Quand passer au niveau supérieur ?

Passez à une mise en demeure ou à un avocat si :

* la personne nie malgré les preuves ;
* le morceau génère des revenus ;
* un label, une marque ou une plateforme est impliqué ;
* votre nom est exclu des crédits ;
* l’usage continue après demande de retrait ;
* une exclusivité ou une cession est en jeu.

**À retenir :** ne confondez pas inspiration et reprise exploitable. Mais si votre enregistrement ou votre composition est clairement réutilisé, traitez le sujet comme un dossier de droits, pas comme une dispute d’ego.

## 6.17 Que faire si votre beat est utilisé dans un podcast ou une émission radio ?

### Le problème

Un podcast, une émission radio, une web radio ou une vidéo conversationnelle peut utiliser votre beat en intro, en fond sonore, en jingle ou en habillage sans vous demander de licence.

Ce n’est pas forcément de la “sync” au sens classique publicité/film/image, mais c’est bien une exploitation publique ou éditoriale de votre musique. Il faut donc vérifier l’usage, la durée, le contexte et les droits concernés.

### Questions à poser

* Le beat est-il utilisé comme générique, fond sonore, jingle ou extrait ?
* L’émission est-elle monétisée ?
* Le podcast est-il diffusé sur Spotify, Apple Podcasts, YouTube, radio ou site web ?
* L’usage est-il ponctuel ou récurrent ?
* Le beat est-il crédité ?
* Une licence a-t-elle été signée ?
* Le beat contient-il des samples ou ayants droit tiers ?

### Première action

Constituez une preuve simple :

* lien de l’épisode ;
* horodatage précis ;
* capture écran ;
* extrait audio de comparaison ;
* preuve de création du beat ;
* preuve de publication ou d’envoi antérieur.

### Message de régularisation

> Bonjour [Nom], j’ai constaté l’utilisation de mon beat [titre] dans votre podcast/émission [nom], épisode [titre/lien], autour de [horodatage]. Je suis ouvert à une régularisation simple : crédit, licence adaptée à l’usage, ou retrait si vous préférez. Merci de me confirmer le cadre d’utilisation et la durée prévue.

### Trois issues possibles

| Issue | Quand l’utiliser |
| --- | --- |
| Crédit + autorisation gratuite | Usage faible, relation utile, pas de monétisation importante |
| Licence payante | Usage régulier, émission monétisée, marque, sponsor ou audience significative |
| Retrait | Usage non souhaité, contexte problématique, refus de discussion |

### Quand consulter ?

Consultez un professionnel si l’usage concerne :

* une radio nationale ;
* une marque ou un sponsor ;
* une campagne récurrente ;
* une diffusion internationale ;
* un conflit sur la propriété ;
* un morceau déjà distribué avec plusieurs ayants droit.

**À retenir :** un podcast n’est pas une zone gratuite. Un usage sonore éditorial peut être cadré calmement, avec preuve, crédit, licence ou retrait.

## 6.18 Que faire si votre beat est utilisé dans un NFT ou un projet Web3 ?

### Le problème

Un acheteur peut utiliser votre beat dans un NFT, une collection numérique, un jeu blockchain, un métavers, un token, une expérience interactive ou une vente liée à une crypto-monnaie sans que vous l’ayez prévu.

Le danger n’est pas seulement l’usage du fichier. Le danger est la revente, la promesse faite aux acheteurs et l’ambiguïté sur les droits transférés.

### Ce qu’il faut comprendre simplement

Un NFT ne transfère pas automatiquement les droits d’auteur, les droits voisins ou les droits sur le master. Mais le marketing autour du NFT peut faire croire à l’acheteur qu’il possède plus qu’un simple objet numérique.

### Clause simple à ajouter

> La licence n’autorise pas l’utilisation du beat, des stems, du master ou de tout élément livré dans un NFT, une collection blockchain, un token, un jeu Web3, un métavers ou tout dispositif numérique impliquant revente, rareté artificielle ou transfert d’actif numérique, sauf accord écrit spécifique.

### Si l’usage existe déjà

1. Capturez la page NFT ou marketplace.
2. Notez l’adresse du projet, le nom de la collection et les ventes visibles.
3. Sauvegardez les descriptions marketing.
4. Identifiez qui vend quoi : fichier audio, accès, œuvre visuelle, morceau complet.
5. Demandez retrait ou régularisation.
6. Consultez si le montant ou la visibilité est significatif.

### Message type

> Bonjour [Nom], j’ai constaté que mon beat [titre] semble être utilisé dans votre projet NFT/Web3 [lien]. Ma licence actuelle n’autorise pas ce type d’exploitation. Merci de me préciser les droits que vous pensez détenir et de suspendre la vente ou l’usage le temps de clarifier la situation.

**À retenir :** un NFT n’est pas magique. C’est une exploitation commerciale supplémentaire. Si elle n’est pas prévue, elle doit être autorisée séparément.

## 6.19 Que faire si votre beat est utilisé sans autorisation sur une plateforme chinoise ?

### Le problème

La Chine a ses propres plateformes, ses propres usages, ses propres barrières linguistiques et ses propres circuits de retrait. Vous pouvez découvrir un beat ou un morceau dérivé sur QQ Music, Kugou, Kuwo, WeSing, NetEase Cloud Music, Douyin ou un autre service sans savoir à qui parler.

Tencent Music indique exploiter notamment QQ Music, Kugou Music, Kuwo Music et WeSing ; cela montre que certaines plateformes chinoises fonctionnent par écosystèmes plutôt que comme une seule boutique isolée. Avant d’agir, identifiez donc précisément la plateforme, le compte, le distributeur éventuel et l’ISRC si disponible.

### Réflexe en 6 étapes

1. Capturer la page en entier : titre, artiste, compte, URL, date, captures écran.
2. Relever les informations visibles : label, distributeur, ISRC, crédits, durée, date de sortie.
3. Comparer avec votre beat original : fichier daté, export, projet DAW, preuve d’envoi.
4. Chercher le canal officiel de support ou de réclamation droits de la plateforme.
5. Contacter d’abord en anglais simple ; utiliser une traduction chinoise relue si l’enjeu monte.
6. Passer par un distributeur, un avocat ou un intermédiaire local si la plateforme ne répond pas.

### Message type en anglais

> Hello, I am the creator and rights holder of the beat/instrumental titled “[Title]”. I have found an unauthorized use of this work on your platform at this link: [URL]. I did not grant a license for this use. Please provide information about the uploader, distributor and rights claim, or remove/disable the content while the matter is clarified.

### Message type en chinois simplifié à faire relire

> 您好，我是音乐作品/伴奏《[Title]》的创作者和权利人。我发现该作品在贵平台链接 [URL] 被未经授权使用。我没有授权该使用。请提供上传者、发行方和权利声明的信息，或在问题澄清前下架/限制该内容。

Ce texte doit être relu avant envoi si l’enjeu est important.

### Prudence

Ne menacez pas une plateforme étrangère avec des textes juridiques que vous ne maîtrisez pas. Restez factuel : qui vous êtes, quelle œuvre est concernée, quel lien pose problème, quelle preuve vous avez, quelle action vous demandez.

**À retenir :** en Chine, la première victoire n’est pas le contentieux. C’est l’identification correcte de la plateforme, du distributeur et du canal de réclamation.

## 6.20 Que faire si votre beat est utilisé dans une sortie posthume ?

### Le problème

Un artiste peut enregistrer sur votre beat, puis décéder avant la sortie. Quelques mois ou années plus tard, sa succession, son label, sa famille, son manager ou un distributeur peut publier le morceau sans clarifier votre licence, vos splits, vos crédits ou votre rôle sur le master.

C’est une situation sensible : il faut rester humain, mais ne pas abandonner vos droits.

### Ce qu’il faut vérifier

* Existait-il une licence signée avant le décès ?
* Le paiement avait-il été fait ?
* Les splits étaient-ils écrits ?
* Le morceau était-il finalisé ?
* Qui contrôle désormais les droits de l’artiste ?
* Qui distribue la sortie posthume ?
* Le beatmaker est-il crédité ?
* Le master final a-t-il été modifié ?

### Message prudent

> Bonjour [Nom], j’ai appris que le morceau [titre] enregistré par [artiste] sur mon beat [titre] est en cours de sortie / a été publié. Je respecte évidemment le contexte sensible de cette sortie. Pour que tout soit propre, j’aimerais vérifier la licence, les crédits, les splits, l’ISRC, le distributeur et le cadre d’exploitation du master. Je suis disponible pour régulariser cela calmement.

### Si rien n’était écrit

S’il n’y avait aucun écrit, n’inventez pas un accord après coup. Reconstituez :

* échanges ;
* fichiers envoyés ;
* preuves de paiement ;
* versions enregistrées ;
* témoins éventuels ;
* dates ;
* crédits proposés ;
* intention de sortie.

### Quand consulter ?

Consultez rapidement si :

* le morceau a un potentiel commercial fort ;
* un label ou une succession conteste votre rôle ;
* la sortie est déjà distribuée ;
* des revenus sont générés ;
* votre nom est absent ;
* le master est exploité en publicité, documentaire ou campagne.

**À retenir :** une sortie posthume demande plus de tact, pas moins de clarté. La meilleure protection reste un contrat et une split sheet avant tout enregistrement important.

* Créez un dossier `LEGAL_ARCHIVES`.

## 🧠 Coin du psy — “Parler de splits, c’est radin”

**La peur :** “Si je parle de pourcentages, je vais casser l’ambiance. On va croire que je pense seulement à l’argent.”

**La réalité :** Ne pas parler de splits ne rend pas la collaboration plus pure. Ça la rend plus dangereuse. Les personnes sérieuses préfèrent clarifier avant que le morceau sorte. Le flou est cool au début, toxique à la fin.

**À répéter :** “Clarifier les parts, c’est respecter le travail de chacun.”

## Récap’ 30 secondes

* Vous n’avez pas besoin d’être juriste, mais vous devez écrire les accords.
* Les samples doivent être vérifiés avant une exploitation sérieuse.
* La split sheet protège la relation avant de protéger l’argent.
* Un morceau officiellement distribué doit être suivi avec son ISRC, son distributeur, ses crédits et votre rôle exact sur le master.
* Une offre de label doit être relue comme un engagement de droits, pas comme une validation de votre talent.
* Un label qui ne paie pas doit être traité avec preuves, relances datées et mise en demeure si nécessaire.
* Un beat utilisé sans licence se traite avec constat, preuves, relance, régularisation, plateforme et mise en demeure si nécessaire.
* Un usage par une marque doit être traité comme un usage commercial potentiellement plus large : documentez avant de négocier.
* Un usage par une IA générative doit être traité avec clauses, preuves, demande d’explication, retrait ou régularisation selon le cas.
* Un autre beatmaker qui sample votre travail doit être traité avec preuves, comparaison claire, contact écrit et régularisation si l’exploitation est réelle.
* Un usage podcast/radio doit être documenté avec horodatage, support de diffusion, contexte et demande de licence ou de retrait.
* Les usages NFT/Web3, Chine et sorties posthumes ne doivent pas être improvisés : identifiez le support, les ayants droit, les preuves et les interlocuteurs avant d’agir.

# Partie 7 — Se rendre visible et trouver des clients

## Problème

Beaucoup de beatmakers confondent visibilité et bruit.

Poster tous les jours sans direction ne construit pas une activité. Envoyer 100 DM copiés-collés ne construit pas une relation. Accumuler des vues sans offre claire ne vend pas forcément.

> *💔 Pour Camille : tu n’as pas besoin d’être partout. Tu dois être régulière sur deux canaux maximum.*

## 7.1 TikTok et YouTube Shorts

Mais le contenu doit servir une action : écouter, commenter, demander le catalogue, rejoindre une liste, acheter une licence.

* Beat breakdown : drums, 808, mélodie, FX.

* Story courte : “J’ai fait ce beat pour un artiste qui veut une vibe nocturne.”
* Erreur de beatmaker : “Pourquoi votre beat ne se vend pas.”

# Partie 8 — S’ouvrir aux marchés globaux sans se perdre

## Problème

La musique circule mondialement. Un beatmaker peut collaborer avec un artiste d’un autre pays sans quitter sa chambre.

Mais l’international ne doit pas devenir une fuite. Avant de viser l’étranger, assurez-vous que votre catalogue, vos licences, vos fichiers et vos droits sont propres.

> *👶 Pour Léo : ne commence pas ici si tes fichiers sont encore en vrac. L’international amplifie le désordre.*

> *💼 Pour Sarah : choisis un seul marché test pendant 30 jours. Pas dix pays en même temps.*

> *🌍 Pour Mamadou : cette partie est ton terrain. Mais avance avec méthode, pas avec ego.*

> *💔 Pour Camille : l’international ne doit pas devenir une pression de plus. Il doit devenir une option structurée.*

## 8.1 Pourquoi envisager l’international ?

Vous devez envisager l’international pour trois raisons :

* certains styles circulent mieux hors de votre marché local ;
* des artistes étrangers cherchent des sonorités nouvelles ;
* la diversification réduit votre dépendance à une seule scène.

Mais vous devez garder une règle : pas d’international sans base propre.

Avant de contacter un artiste étranger, vous devez avoir :

* 10 beats propres ;
* fichiers MP3 / WAV / stems prêts ;
* titres clairs ;
* tags en anglais ;
* fiche de prix ;
* licence compréhensible ;
* paiement traçable ;
* archives des échanges.

Copier les codes américains sans identité. Si vous faites la même chose que tout le monde, vous devenez invisible dans le plus grand marché.

Afrique francophone, Nigeria, Ghana, Côte d’Ivoire, Sénégal, Cameroun : les scènes sont dynamiques, créatives et très connectées.

* afrobeat ;

Traiter “l’Afrique” comme un seul pays. Les scènes, langues, accents, références et budgets varient énormément.

## 8.5 Brésil

Le Brésil a une culture musicale puissante : funk, trap, pop urbaine, afro, club, rap.

L’Inde a un marché vaste, jeune, multilingue et très numérique. Les opportunités existent, mais la diversité culturelle est énorme.

Commencez par artistes indépendants, rappeurs, créateurs YouTube, projets digitaux. Évitez de signer des accords complexes sans relecture.

Envoyer un dossier amateur. Sur ce type de marché, la forme compte autant que la vibe.

### Méthode

* préparez une page sobre ;
* évitez le spam ;
* proposez des licences non exclusives au départ ;
* archivez tous les échanges ;
* faites relire les contrats importants.

### Erreur à éviter

Penser que “japonais approximatif + emoji” suffit. Le respect culturel compte.

## 8.9 Chine

La Chine peut être attractive, mais ce n’est pas un raccourci magique. Les plateformes, usages, contrats, délais, paiements et barrières linguistiques exigent de la prudence.

### Ce qu’il faut éviter

* signer un contrat incompris ;
* céder trop de droits ;
* croire une promesse trop belle ;
* envoyer des exclusivités sans acompte ;
* négliger la traduction ;
* ignorer les restrictions de plateforme.

### Méthode prudente

Commencez par :

* licences non exclusives ;
* intermédiaires fiables ;
* contrats bilingues relus ;
* paiements sécurisés ;
* catalogue sans samples risqués ;
* échanges archivés.

## 8.10 Marché hispanophone

Le marché hispanophone est immense : Espagne, Mexique, Colombie, Argentine, Chili, Pérou, République dominicaine, Porto Rico et au-delà.

### Genres porteurs

* reggaeton ;
* trap latino ;
* urbano latino ;
* afro latino ;
* pop urbaine ;
* drill hispanophone.

### Plateformes clés

YouTube est énorme pour la découverte. Spotify Latino compte aussi beaucoup pour l’écoute et les playlists.

### Hashtags locaux

* `#beatmakerargentino`

> Hola [Nombre], escuché tu tema [título]. Me gusta la energía y la dirección. Tengo 3 beats en una vibra [estilo] que podrían encajar con tu universo. Si quieres, te mando un link privado.

Faites relire si l’enjeu est important.

## 8.11 Agrégateurs, sous-éditeurs, sync

Selon votre objectif, vous pouvez travailler avec différents intermédiaires. Ne mettez pas tout dans le même sac.

### Distributeurs numériques

Ils servent surtout à distribuer des morceaux sur les plateformes comme Spotify, Apple Music, Deezer, YouTube Music ou Amazon Music.

Exemples connus : DistroKid, TuneCore, CD Baby, iMusician, Ditto Music, LANDR Distribution.

Pour un beatmaker, ils deviennent utiles si vous sortez vos propres projets instrumentaux, si vous accompagnez un artiste ou si vous structurez une sortie officielle. Ils ne remplacent pas une licence claire avec l’artiste.

### Plateformes de vente ou leasing de beats

Elles servent à présenter, vendre ou licencier vos beats.

Exemples connus : BeatStars, Airbit, Traktrain, Soundee.

Elles peuvent aider à vendre, mais elles ne font pas tout. Votre catalogue, vos titres, vos tags, votre suivi client et vos contrats restent votre responsabilité.

### Librairies de synchronisation

Elles placent des musiques pour image : publicité, YouTube, télévision, jeu vidéo, documentaire, contenu de marque.

Exemples connus : Artlist, Epidemic Sound, Musicbed, Audio Network, Songtradr, Pond5, PremiumBeat.

Lisez les conditions avant d’envoyer votre catalogue. Certaines plateformes demandent une exclusivité, d’autres non. Certaines peuvent limiter ce que vous pouvez faire ailleurs avec les mêmes morceaux.

### Sous-éditeurs et agences de placement

Ils peuvent représenter vos œuvres sur un territoire ou auprès de clients professionnels. C’est potentiellement puissant, mais plus contractuel.

À vérifier absolument : durée, territoire, commission, exclusivité, reporting, droit de sortie, droits concernés.

### Règle simple

Un distributeur met votre musique en ligne. Une plateforme de beats aide à vendre des licences. Une librairie sync cherche des placements image. Un sous-éditeur représente des droits. Ce ne sont pas les mêmes métiers.

### Questions à poser avant de signer

* Quelle durée ?
* Quel territoire ?
* Quelle commission ?
* Exclusif ou non exclusif ?
* Quels droits sont cédés ?
* Comment les revenus sont-ils reportés ?
* Puis-je sortir de l’accord ?
* Qui collecte quoi ?

## 8.12 Paiements, langue, arnaques

### Paiements

Utilisez des solutions traçables. Évitez les arrangements flous. Gardez preuves, factures, captures, contrats et historiques d’échange.

### Langue

Ne signez pas un contrat dans une langue que vous ne comprenez pas. Utilisez une traduction, puis faites relire si les enjeux sont importants.

### Arnaques fréquentes

* faux manager ;
* fausse opportunité de placement ;
* demande de frais avant paiement ;
* promesse de célébrité ;
* exclusivité demandée sans budget ;
* compte Instagram douteux.

**À retenir :** l’international multiplie les opportunités, mais aussi les malentendus.


## 8.13 Les droits voisins à l’international : tableau des CMO par pays

### Le problème

L’international ne se limite pas à vendre un beat en anglais. Quand un morceau circule hors de France, différentes sociétés peuvent intervenir selon les territoires, les droits concernés et votre rôle réel.

La règle : ne vous affiliez pas partout au hasard. Documentez d’abord vos enregistrements.

### Tableau de repères

| Territoire | Organisme à connaître | Profil concerné | Point de vigilance |
| --- | --- | --- | --- |
| France | SCPP / SPPF | producteurs phonographiques | être réellement producteur du master |
| France | ADAMI / SPEDIDAM | artistes-interprètes | interprétation enregistrée et conditions d’admission |
| États-Unis | SoundExchange | artistes et ayants droit du master selon cas | royalties numériques spécifiques, inscription et claim |
| Royaume-Uni | PPL | performers et recording rightsholders | collecte UK et internationale selon critères |
| Allemagne | GVL | artistes-interprètes et producteurs | droits voisins allemands et international |
| Espagne | AIE / AGEDI | AIE interprètes, AGEDI producteurs | ne pas confondre interprète et producteur |
| International | sociétés partenaires / accords de réciprocité | selon territoire | critères variables selon pays |

### Méthode en cinq étapes

1. Créez un tableau de vos morceaux officiellement sortis.
2. Ajoutez ISRC, distributeur, date, artistes, crédits, pays principaux.
3. Identifiez votre rôle : compositeur, interprète, producteur du master, simple concédant.
4. Vérifiez l’organisme adapté à ce rôle.
5. Demandez conseil avant de signer un mandat exclusif long ou une représentation globale.

### Attention aux doublons

Ne mandatez pas deux structures pour collecter exactement les mêmes droits sur le même territoire sans comprendre les conséquences. Cela peut créer des conflits de collecte, des blocages ou des retards.

# Partie 10 — Revenus passifs et diversification

## Problème

Beaucoup de beatmakers veulent des revenus passifs avant d’avoir des revenus actifs propres.

C’est une erreur.

Les revenus passifs ne sont pas magiques. Ils demandent un catalogue propre, des droits clairs, des fichiers exploitables et une stratégie.

Un revenu passif, dans ce livre, veut dire : un revenu qui peut continuer à arriver après le travail initial. Mais ce travail initial doit être sérieux.

> *👶 Pour Léo : ne commence pas par là. Construis d’abord tes 10 beats propres.*

> *💼 Pour Sarah : cette partie peut stabiliser tes revenus si ton catalogue est déjà structuré.*

> *🌍 Pour Mamadou : la diversification internationale peut devenir ton levier principal.*

> *💔 Pour Camille : les revenus passifs doivent alléger ton énergie, pas ajouter dix nouveaux chantiers.*

**Note sur les prix et revenus :** les montants, pourcentages, commissions et exemples de revenus passifs varient fortement selon les plateformes, pays, contrats, fiscalités, volumes d’écoute et niveaux de catalogue. Ne basez jamais une décision importante uniquement sur un exemple. Vérifiez les conditions réelles avant de signer.

## 10.1 Synchronisation : films, pubs, jeux vidéo

La synchronisation, ou sync, signifie l’utilisation d’une musique avec une image : film, série, publicité, jeu vidéo, documentaire, vidéo de marque, contenu digital.

Pour démarrer, vous devez préparer des beats faciles à utiliser.

### Ce que les superviseurs musicaux aiment

* droits clairs ;
* pas de sample risqué ;
* stems disponibles ;
* versions courtes ;
* version sans drums ;
* version 30 secondes ;
* métadonnées propres ;
* mood identifiable.

### Exemple de metadata

* Titre : Night Runner
* Style : Trap cinematic
* Mood : dark, tension, urban
* BPM : 142
* Tonalité : F minor
* Durée : 2:34
* Instruments : 808, synth, hats, pads
* Droits : original, no uncleared samples
* Contact : email

### Action simple

Choisissez 5 beats sans samples risqués et préparez pour chacun : full version, 30 secondes, instrumental, stems, fiche metadata.

## 10.2 Royalties : comprendre les bases

Les royalties sont des revenus issus de l’exploitation d’une œuvre ou d’un enregistrement.

Selon votre pays, votre statut et le type d’exploitation, vous pouvez devoir vous renseigner auprès de sociétés de gestion collective comme la SACEM en France, ou d’équivalents et sociétés sœurs à l’international. Pour les États-Unis, certains revenus peuvent passer par des organisations ou services spécifiques selon les droits concernés.

Le point important : ne mélangez pas tout.

### À clarifier

* Qui est auteur / compositeur ?
* Qui possède le master ?
* Qui déclare l’œuvre ?
* Qui collecte quoi ?
* Quels pourcentages sont écrits ?
* Dans quel pays l’œuvre est exploitée ?

### Erreur à éviter

Attendre que le morceau fasse des streams pour parler des parts. À ce moment-là, la discussion devient plus tendue.

## 10.3 Leasing récurrent : abonnement beatmaker

Le leasing récurrent consiste à proposer un accès régulier à des beats sous forme d’abonnement ou de pack mensuel.

Exemple :

* 29 €/mois : accès à 3 MP3 previews + réduction sur licence ;
* 79 €/mois : 2 licences standard incluses ;
* 149 €/mois : 1 licence unlimited + sélection personnalisée.

Ce modèle doit rester simple. Sinon, vous créez une usine à confusion.

### Pour qui ?

* artistes réguliers ;
* créateurs de contenu ;
* rappeurs qui sortent beaucoup ;
* studios locaux ;
* collectifs.

### Règles à écrire

* nombre de beats inclus ;
* type de licence ;
* durée ;
* résiliation ;
* exclusivité ou non ;
* livraison ;
* limites d’usage.

## 10.4 Librairies musicales : Artlist, Epidemic Sound et alternatives

Les librairies musicales permettent à des créateurs, marques ou productions d’utiliser des musiques sous licence.

Certaines plateformes fonctionnent sur sélection. D’autres ont des conditions particulières. Lisez toujours les contrats.

### Ce qu’il faut vérifier

* exclusivité demandée ;
* durée du contrat ;
* territoires ;
* revenus ;
* possibilité de retirer les morceaux ;
* droits conservés ;
* obligation de livrer des stems ;
* règles sur les samples.

### Erreur à éviter

Uploader votre meilleur catalogue sur une plateforme sans lire si vous bloquez vos droits ailleurs.


## 10.5 Le beatmaker-artiste : sortir vos projets instrumentaux

### Le problème

Beaucoup de beatmakers ne sortent jamais leurs propres projets. Ils vendent des beats, postent des snippets, mais ne construisent pas de catalogue public sous leur nom.

Pourtant, sortir un projet instrumental peut servir plusieurs objectifs :

* créer une vitrine officielle ;
* générer des liens écoutables ;
* documenter un catalogue ;
* apprendre la distribution ;
* créer des ISRC ;
* tester une esthétique ;
* préparer la sync ;
* exister comme artiste-producteur.

### Ce qu’il faut préparer

Avant de distribuer un projet instrumental, préparez :

* titres définitifs ;
* fichiers WAV propres ;
* artwork ;
* métadonnées ;
* ISRC si vous les fournissez, ou ceux générés par le distributeur ;
* UPC de la sortie ;
* crédits ;
* absence de samples risqués ;
* stratégie de sortie ;
* plan de publication court.

### Choisir un distributeur

Un distributeur sert à mettre votre musique sur les plateformes. Il ne remplace pas :

* une déclaration d’œuvre ;
* une split sheet ;
* une société de gestion ;
* un contrat de collaboration ;
* une stratégie de promotion.

Comparez :

* prix annuel ou commission ;
* conservation des droits ;
* génération ISRC / UPC ;
* rapidité de paiement ;
* accès aux stores ;
* retrait possible ;
* support ;
* gestion des crédits.

### Plan de sortie minimal

| Moment | Action |

| J-14 | envoyer au distributeur |

| J+7 | partager un breakdown |
| J+30 | analyser écoutes, playlists, retours |

### Erreur à éviter

Ne sortez pas un projet instrumental juste pour “faire comme les autres”. Sortez-le avec une intention : vitrine, sync, identité, preuve de sérieux, catalogue public.

**Règle simple :** un projet instrumental bien documenté vaut mieux que 40 beats anonymes perdus dans un Drive.


## 10.6 Packs, templates et produits numériques

Mauvais produit : “Pack de sons random volume 1.”

## Annexe G — Guide de survie du beatmaker solo

*10 règles courtes. Ton brut. À relire le lundi matin.*

1. **Un beat par jour, même moche.**
   La constance tue la procrastination. Le beat moyen terminé bat la loop parfaite jamais exportée.

2. **Nommez avant de mixer.**
   Un fichier `beat_final_v3.wav` est une insulte à votre futur vous-même.

3. **Un contrat vaut mieux qu’une promesse.**
   Toujours. Même quand l’artiste est sympa. Surtout quand l’artiste est sympa.

4. **L’artiste qui négocie sur 20 € n’achètera pas à 200 €.**
   Passez votre chemin. Votre énergie est un budget.

5. **Votre catalogue est votre seul vrai actif.**
   Sauvegardez-le comme votre vie. Parce qu’en partie, c’est votre vie créative.

6. **L’international commence par un tag en anglais.**
   Pas par un vol en avion. Pas par un rêve flou. Par un fichier propre.

7. **Ne ghostez pas un client.**
   Une relance polie vend plus qu’un nouveau beat parfait caché dans un dossier.

8. **L’IA ne vous remplacera pas.**
   Le beatmaker organisé, humain et constant, lui, peut prendre votre place.

9. **Vous n’êtes pas votre beat.**
   Un beat non vendu n’est pas un échec personnel. C’est une donnée.

10. **Commencez petit, mais commencez aujourd’hui.**
    Le système se construit avec une action. Pas avec une promesse.

## Annexe H — Checklist de l’auto-sabotage

À faire dès que vous sentez que vous tournez en rond.

Cochez les cases qui vous correspondent :

* [ ] Vous passez 2h à chercher le bon sample au lieu de finir le beat.
* [ ] Vous avez 15 onglets ouverts sur “comment mixer la 808” mais aucun beat fini aujourd’hui.
* [ ] Vous ne répondez pas aux DM d’artistes parce que “le beat n’est pas parfait”.
* [ ] Vous baissez votre prix dès qu’un artiste dit “c’est cher” sans même négocier.
* [ ] Vous n’osez pas envoyer de contrat parce que “ça fait trop pro, ça va lui faire peur”.
* [ ] Vous passez plus de temps à regarder des tutoriels qu’à produire ou vendre.
* [ ] Vous attendez “d’être prêt” pour vendre : plus de followers, meilleur mix, plus de beats.
* [ ] Vous comparez votre début à la réussite d’un beatmaker qui produit depuis 8 ans.
* [ ] Vous avez changé de DAW, de casque ou de plugin principal 3 fois en 12 mois.
* [ ] Vous n’avez pas fait de sauvegarde depuis plus d’un mois.
* [ ] Vous ne savez pas retrouver l’ISRC ou le distributeur des morceaux déjà sortis.

### Résultats

**1 à 3 cases : sabotage léger.**
Vous avancez, mais vous ralentissez sans vous en rendre compte. Choisissez une action simple aujourd’hui.

**4 à 6 cases : sabotage modéré.**
Le système de ce livre doit devenir votre priorité. Relisez les Coins du psy et appliquez le plan 90 jours.

**7 à 10 cases : sabotage sévère.**
Arrêtez tout. Prenez une feuille. Notez : “Qu’est-ce que je fuis vraiment ?” Puis revenez au Manifeste.

# Annexe J — Bases fiscales pour le beatmaker indépendant (France)

**Avertissement :** cette annexe donne des repères généraux pour la France. Elle ne remplace pas un conseil personnalisé. Les règles changent selon votre situation, votre chiffre d’affaires, votre statut, votre pays de résidence et l’année fiscale concernée. Consultez un expert-comptable, l’URSSAF, le site officiel Service-Public / Entreprendre ou un centre de gestion compétent avant toute déclaration importante.

## Quel statut choisir ?

La plupart des beatmakers qui commencent à encaisser régulièrement choisissent d’abord le statut de **micro-entrepreneur**, anciennement appelé auto-entrepreneur.

Ce statut peut convenir pour démarrer une activité simple : ventes de licences, prestations de production, leasing, packs ou services liés à la musique.

Mais il ne convient pas à toutes les situations.

Si vous signez avec des labels, vendez beaucoup à l’étranger, avez de gros frais, touchez des royalties complexes ou travaillez avec plusieurs ayants droit, demandez conseil.

## Seuils de chiffre d’affaires

Les seuils de chiffre d’affaires changent avec la législation. Ne copiez jamais un chiffre trouvé dans un livre sans le vérifier.

Au moment de préparer cette V13, les sources officielles françaises indiquent des seuils distincts selon la nature de l’activité : prestations de services, ventes de marchandises, activités mixtes, BIC ou BNC. Pour un beatmaker, la qualification exacte peut dépendre de ce que vous vendez : licence, prestation, produit numérique, accompagnement, formation, pack de sons.

**Règle simple :** avant de déclarer, vérifiez votre catégorie d’activité sur les sites officiels ou avec un expert-comptable.

## Ce que la micro-entreprise permet

* Déclaration simplifiée.
* Paiement des cotisations selon le chiffre d’affaires encaissé.
* Gestion accessible pour commencer.
* Franchise de TVA possible tant que vous restez sous les seuils applicables.
* Démarrage rapide via les démarches officielles.

## Ce qu’elle permet mal

* Déduire vos vrais frais : matériel, plugins, samples, abonnement cloud, ordinateur, casque.
* Gérer des droits complexes entre plusieurs personnes.
* Optimiser une activité avec beaucoup de charges.
* Répondre à certains clients professionnels étrangers qui demandent un cadre TVA ou contractuel précis.

Un statut simple n’est pas toujours le meilleur statut quand votre activité grandit.

## La facture obligatoire

Pour toute vente à un professionnel, vous devez émettre une facture. Cela peut concerner un label, une société, un artiste déclaré, un studio ou une structure culturelle.

Pour un particulier, un reçu ou une facture simplifiée peut suffire selon le contexte. Dans le doute, facturez proprement.

Une facture doit contenir au minimum :

* votre nom ou nom commercial ;
* votre adresse professionnelle ;
* votre SIRET si vous avez un statut ;
* le nom et l’adresse du client ;
* la date d’émission ;
* un numéro de facture unique ;
* la description précise de la prestation ;
* le montant ;
* la mention de TVA applicable ou non ;
* les conditions de paiement.

Exemple de description propre :

> Licence non exclusive du beat “Midnight Pressure” — MP3 + WAV — usage musical indépendant selon contrat joint.

## TVA : quand s’en préoccuper ?

En micro-entreprise, vous pouvez bénéficier d’une franchise en base de TVA tant que vous restez sous les seuils applicables.

Cela signifie :

* vous ne facturez pas la TVA ;
* vous ne récupérez pas la TVA sur vos achats ;
* vous devez ajouter la mention adaptée sur vos factures si vous êtes concerné.

La mention courante est :

> TVA non applicable, article 293 B du CGI.

Mais ne l’utilisez pas mécaniquement si votre situation a changé. Vérifiez toujours votre régime TVA.

## Clients étrangers

Pour les paiements internationaux, consultez aussi l’Annexe Q. Elle présente les réflexes de base sur les retenues à la source, les plateformes étrangères et le formulaire W-8BEN pour les revenus de source américaine.

Si vous vendez un beat à un artiste au Nigeria, au Brésil, au Japon, aux États-Unis ou ailleurs, le revenu doit être déclaré en France si vous êtes résident fiscal français et que l’activité relève de votre activité déclarée.

Ce n’est pas parce que l’argent vient de l’étranger qu’il devient invisible, hors taxe ou “à part”.

**Règle simple :** tout paiement reçu sur PayPal, Stripe, Wise ou votre compte bancaire doit être suivi et déclaré selon votre situation.

La TVA avec des clients étrangers peut dépendre du pays, du statut du client, du type de prestation et du lieu d’imposition. Ne devinez pas. Vérifiez.

## Ce que vous devez faire dès maintenant

1. **Si vous gagnez plus que quelques ventes isolées :** renseignez-vous sur la micro-entreprise via les sites officiels.
2. **Conservez toutes vos preuves :** factures, paiements, contrats, reçus, exports livrés.
3. **Séparez vos finances :** même quand ce n’est pas encore obligatoire, un compte dédié rend votre activité plus lisible.
4. **Suivez votre chiffre d’affaires encaissé :** notez ce qui arrive réellement sur vos comptes.
5. **Anticipez les charges :** ne dépensez pas 100 % de ce que vous encaissez.

## Compte bancaire dédié

Au-delà de certains seuils et selon votre situation, un compte bancaire dédié peut devenir obligatoire. Même avant l’obligation, il reste fortement conseillé.

Un compte dédié vous aide à voir :

* ce que l’activité rapporte ;
* ce que l’activité coûte ;
* ce qui doit être déclaré ;
* ce que vous pouvez réinvestir ;
* ce que vous devez mettre de côté.

## Droits voisins et fiscalité

Les revenus issus de droits voisins, de distribution, de plateformes, de sociétés de gestion ou d’organismes étrangers doivent être suivis comme des revenus professionnels ou patrimoniaux selon votre statut, votre activité et leur nature exacte.

Ne mélangez pas :

* vente de licence ;
* prestation de production ;
* royalties de distribution ;
* droits d’auteur ;
* droits voisins ;
* rémunération équitable ;
* copie privée ;
* avance ou acompte.

Chaque catégorie peut avoir un traitement différent. Notez la source, la date, le montant brut, les frais retenus, le pays, l’organisme payeur et le morceau concerné.

**Règle simple :** si l’argent arrive, il doit être traçable et déclarable.

# Annexe K — Exemple de contrat rempli (anonymisé)

**Avertissement :** cet exemple est pédagogique. Il montre comment remplir une licence simple. Il ne remplace pas un contrat rédigé ou relu par un avocat. Adaptez chaque clause à votre pays, votre situation, votre statut et votre niveau d’exploitation.

## Exemple — Licence non exclusive remplie

### 1. Parties

Nom : ZK Beats

**Artiste / Licencié :**
Nom d’artiste : Nox Verse
Nom civil : [Nom anonymisé]

Pays : France

BPM : 140
Tonalité : F minor
Style : Trap mélodique
Mood : Dark / émotionnel
ISRC du morceau final : à transmettre par l’artiste si distribution officielle
Distributeur : à confirmer avant sortie

### 3. Type de licence

Type : **Licence non exclusive standard**

Cette licence autorise l’artiste à utiliser le beat dans un morceau original intitulé provisoirement **“Night Calls”**.

Le beatmaker conserve la propriété du beat et peut continuer à vendre des licences non exclusives du même beat à d’autres artistes, sauf accord contraire écrit.

### 4. Fichiers livrés

* MP3 preview sans tag final.
* WAV master stéréo.
* Fichier texte avec BPM, tonalité et crédits.

### 5. Prix et paiement

Prix : **79 € TTC ou net selon régime applicable**

La licence devient active uniquement après paiement complet.

L’artiste peut :

* enregistrer sa voix sur le beat ;
* distribuer le morceau sur les plateformes numériques ;
* publier le morceau sur YouTube, TikTok, Instagram et autres réseaux ;
* monétiser le morceau dans les limites prévues par la licence ;
* utiliser le morceau pour sa promotion artistique personnelle.

L’artiste ne peut pas :

* revendre le beat seul ;
* transférer la licence à un autre artiste ;
* présenter le beat comme sa propre production ;
* vendre une exclusivité sur le beat ;
* utiliser le beat dans une publicité, un film, un jeu vidéo ou une synchronisation commerciale ;
* utiliser le beat, les stems ou les fichiers livrés pour entraîner une intelligence artificielle ;
* déposer le beat seul auprès d’un service de Content ID sans accord écrit.

### 8. ISRC, distribution et droits voisins

Si l’artiste distribue officiellement le morceau final, il s’engage à transmettre au beatmaker l’ISRC, le nom du distributeur, la date de sortie, les liens officiels et les crédits utilisés.

Les droits sur le master final doivent être clarifiés séparément si les parties coproduisent l’enregistrement final.

### 9. Crédits

Crédit recommandé :

> Prod. by ZK Beats

À utiliser dans la description YouTube, les crédits plateformes, le dossier presse ou toute communication officielle quand c’est possible.

### 10. Samples

Le beatmaker déclare que le beat est créé sans sample externe non autorisé à sa connaissance.

Si un élément externe est découvert ou revendiqué, les parties s’engagent à discuter avant toute exploitation commerciale importante.

### 11. Splits

Cette licence ne fixe pas automatiquement les splits d’auteur/compositeur du morceau final.

Si l’artiste sort officiellement le morceau, les parties doivent remplir une split sheet séparée pour préciser les pourcentages liés à la composition.

Exemple provisoire à discuter :

| Personne  | Rôle                                 | Pourcentage indicatif |
| --------- | ------------------------------------ | --------------------: |
| ZK Beats  | Beatmaker / compositeur instrumental |                  50 % |
| Nox Verse | Auteur / interprète                  |                  50 % |

### 12. Durée et territoire

Durée : à préciser selon votre modèle.
Territoire : monde entier, sauf restriction écrite.

Ne laissez jamais ces champs vides dans un vrai contrat.

### 13. Signature

Fait le : 18 mai 2027

Signature beatmaker : ______________________

Signature artiste : ______________________

## Pourquoi cet exemple fonctionne

Il est court. Il nomme le beat. Il dit ce qui est livré. Il dit ce qui est interdit. Il sépare la licence du beat et les splits de l’œuvre finale.

Il n’est pas parfait. Mais il est mille fois plus solide qu’un DM : “vas-y c’est bon bro”.

# Annexe N — ISRC, UPC et métadonnées de distribution

## Objectif

Cette annexe sert à éviter une erreur classique : sortir de la musique sans pouvoir la tracer proprement.

Un beatmaker sérieux doit pouvoir répondre rapidement à ces questions :

* quel est le titre exact ?
* quel est l’ISRC ?
* quel est l’UPC de la sortie ?
* qui distribue ?
* qui possède le master ?
* qui est crédité ?
* quel contrat correspond à cette sortie ?
* quelles sociétés de gestion peuvent être concernées ?

## Checklist avant distribution

* [ ] Le titre est définitif.
* [ ] Le fichier WAV final est validé.
* [ ] L’artwork est prêt.
* [ ] Les crédits sont écrits.
* [ ] Les samples sont vérifiés.
* [ ] Les splits sont signés.
* [ ] Le distributeur est choisi.
* [ ] L’ISRC est créé ou attribué.
* [ ] L’UPC est créé pour la sortie.
* [ ] La date de sortie est notée.
* [ ] Les paroles éventuelles sont prêtes.
* [ ] Le dossier juridique est archivé.

## ISRC : erreurs fréquentes

* réutiliser le même ISRC pour deux versions différentes ;
* ne pas noter l’ISRC généré par le distributeur ;
* confondre ISRC et UPC ;

* laisser un artiste déposer un morceau sans récupérer les informations.

## Règle simple

Un fichier peut se perdre. Un lien peut disparaître. Un ISRC bien noté dans un tableau propre permet de retrouver la trace d’un enregistrement.

# Annexe O — Mastering : auto-mastering ou outsourcing

## Le problème

Le mastering est souvent mal compris. Beaucoup de beatmakers veulent que leur preview sonne fort, mais livrent ensuite un fichier trop écrasé pour l’artiste ou l’ingénieur du son.

Votre objectif n’est pas de gagner une guerre de volume. Votre objectif est de livrer le bon fichier pour le bon usage.

## Trois niveaux

| Niveau | Solution | Quand l’utiliser |
| --- | --- | --- |
| Preview | Auto-mastering léger ou limiter propre | Pour faire écouter rapidement |
| Livraison artiste | WAV propre avec marge | Pour enregistrer et mixer |
| Sortie officielle | Mastering dédié | Pour une distribution sérieuse |

## Quand faire soi-même ?

Vous pouvez faire vous-même si :

* c’est une preview ;
* le morceau reste un beat de catalogue ;
* le client veut enregistrer dessus ;
* vous gardez de la marge ;
* vous savez éviter la saturation inutile.

## Quand déléguer ?

Déléguez ou recommandez un ingénieur mastering si :

* sortie officielle importante ;
* label ou sync ;
* clip avec budget ;
* projet EP/album ;
* client exigeant ;
* vous n’êtes pas sûr du rendu ;
* le mix contient des problèmes sérieux.

## Fichiers à livrer pour mastering

* WAV 24 bit ;
* pas de limiteur destructeur sur le master ;
* marge suffisante ;
* stems si demandé ;
* BPM et tonalité ;
* référence sonore ;
* notes d’intention ;
* version actuelle pour comparaison.

## Phrase à dire au client

> Je peux fournir une preview masterisée pour écoute, mais pour une sortie officielle sérieuse, je recommande un mastering dédié à partir du mix final avec la voix.

# Annexe Q — Taxes internationales : W-8BEN, retenues et paiements étrangers

## Avertissement

Cette annexe donne des repères simples. Elle ne remplace pas un expert-comptable, un fiscaliste, une plateforme officielle ou une convention fiscale à jour. Les règles varient selon votre pays de résidence, votre statut, le pays du payeur, le type de revenu, la plateforme et les conventions fiscales applicables.

Le but ici n’est pas de devenir fiscaliste. Le but est d’éviter de perdre de l’argent par ignorance.

## Le problème

Un beatmaker peut recevoir de l’argent depuis plusieurs pays : vente de licence, royalties de distribution, revenus de plateformes, sync, droits voisins, paiement d’un label étranger, librairie musicale ou client international.

Chaque flux peut être traité différemment. Certains payeurs étrangers peuvent appliquer une retenue à la source avant de vous verser l’argent.

Exemple classique : une plateforme américaine peut demander un formulaire fiscal. Si vous ne le fournissez pas correctement, une retenue peut être appliquée, parfois jusqu’à 30 % selon les règles américaines et la situation du bénéficiaire.

## W-8BEN : à quoi ça sert ?

Le W-8BEN est un formulaire fiscal américain utilisé par les personnes physiques étrangères pour certifier leur statut de bénéficiaire étranger auprès d’un payeur ou d’un withholding agent américain.

En clair : si vous êtes une personne non américaine qui reçoit certains revenus de source américaine, la plateforme peut vous demander ce formulaire pour savoir comment traiter la retenue fiscale.

### Point très important

Le W-8BEN ne s’envoie généralement pas directement à l’IRS. Il est transmis au payeur, à la plateforme ou à l’intermédiaire qui vous le demande.

## W-8BEN ou W-8BEN-E ?

| Situation | Formulaire souvent concerné |
| --- | --- |
| Vous êtes une personne physique étrangère | W-8BEN |
| Vous encaissez via une société étrangère | W-8BEN-E |
| Vous êtes une personne américaine | W-9, pas W-8BEN |
| Vous ne savez pas | Demander conseil avant de remplir |

Un beatmaker en nom propre peut souvent être concerné par le W-8BEN. Une société, label, SASU ou autre entité peut être concernée par une autre logique. Ne mélangez pas votre personne physique et votre société.

## Pourquoi ce formulaire peut compter

Sans formulaire valide, certains payeurs peuvent appliquer une retenue maximale ou standard. Avec un formulaire correctement rempli, vous pouvez parfois bénéficier d’un taux réduit ou d’un traitement adapté selon la convention fiscale entre votre pays et les États-Unis.

Cela ne veut pas dire que vous ne payez jamais d’impôt. Cela veut dire que le prélèvement à la source peut être traité différemment. Le revenu peut ensuite rester déclarable dans votre pays de résidence.

## Cas concrets pour beatmakers

### Cas 1 — Plateforme américaine de vente ou de distribution

Vous vendez des licences ou percevez des royalties via une plateforme basée aux États-Unis. Elle vous demande des informations fiscales.

À faire :

* vérifier si la plateforme demande un W-8BEN ;
* remplir les informations exactement comme votre identité fiscale ;
* conserver une copie ;
* noter le taux de retenue appliqué ;
* conserver les relevés annuels ou documents fiscaux fournis.

### Cas 2 — Librairie musicale ou sync américaine

Une librairie ou agence vous verse des revenus de placement.

À faire :

* demander si une retenue à la source est appliquée ;
* demander le formulaire fiscal nécessaire ;
* vérifier si le paiement concerne master, composition, sync, performance ou autre ;
* archiver contrat, relevé, pays, morceau, ISRC et montant brut.

### Cas 3 — Label étranger

Un label étranger vous verse une avance, des royalties ou une rémunération de production.

À faire :

* demander le pays fiscal du payeur ;
* identifier la nature exacte du revenu ;
* vérifier s’il y a retenue à la source ;
* demander un relevé indiquant brut, frais, retenue, net versé ;
* transmettre le dossier à votre comptable.

## Tableau de suivi simple

| Date | Payeur | Pays | Morceau | Nature du revenu | Montant brut | Frais | Retenue | Net reçu | Document fiscal |
| --- | --- | --- | --- | --- | ---: | ---: | ---: | ---: | --- |
| 2027-06-01 | Plateforme US | États-Unis | Night Runner | Royalties | 100 € | 5 € | 30 € | 65 € | W-8BEN / relevé |

## Checklist internationale fiscale

* [ ] Je connais le pays du payeur.
* [ ] Je connais la nature du revenu : licence, royalties, sync, master, droits voisins, prestation.
* [ ] Je sais si le paiement est fait à mon nom ou à ma société.
* [ ] J’ai fourni le bon formulaire fiscal si la plateforme le demande.
* [ ] J’ai conservé le montant brut, les frais, la retenue et le net reçu.
* [ ] J’ai téléchargé les relevés fiscaux disponibles.
* [ ] J’ai noté le morceau, l’ISRC et le contrat concerné.
* [ ] J’ai transmis ou prévu de transmettre ces informations à mon comptable.

## Erreurs fréquentes

* ignorer les formulaires fiscaux demandés par les plateformes ;
* croire que “net reçu” suffit pour comprendre le revenu ;
* oublier le montant brut ;
* mélanger revenus personnels et revenus de société ;
* ne pas conserver les relevés annuels ;
* confondre fiscalité américaine et déclaration française ;
* croire qu’un formulaire fiscal remplace une déclaration locale.

## Phrase simple à retenir

Un revenu international doit toujours être suivi en brut, frais, retenue, net, pays, payeur, morceau et contrat.

**À retenir :** si vous commencez à toucher de l’argent depuis l’étranger, votre tableau de suivi devient aussi important que votre compte bancaire.

**Action finale :** créer un dossier de preuves avec captures, dates, liens et contrats.

### Épisode 10 — Plan 90 jours

**Angle :** le livre n’est pas une décoration. C’est un système à appliquer.

**Action finale :** planifier les 3 premières actions de la semaine.

## Ton recommandé

Le ton doit être direct, sobre, concret, presque intérieur :

* pas professoral ;
* pas “coach motivationnel” artificiel ;
* pas de promesse de richesse rapide ;
* beaucoup d’exemples courts ;
* des phrases qu’un beatmaker peut retenir en studio.

## Structure type d’un épisode

1. Phrase d’accroche.
2. Problème réel.
3. Exemple concret.
4. Règle simple.
5. Action du jour.
6. Phrase à garder.

## Exemple de phrase de clôture

> Vous n’avez pas besoin de tout comprendre aujourd’hui. Vous devez seulement faire une action propre. Un beat renommé, un contrat envoyé, une preuve archivée. Le système commence là.

## Livrables audio possibles

* 10 fichiers MP3 ;
* 10 scripts texte ;
* 10 miniatures simples ;
* 10 posts courts pour annoncer les épisodes ;
* 1 page d’accès dans le toolkit ;
* 1 playlist privée pour les acheteurs du livre.

**À retenir :** le companion audio n’est pas un bonus décoratif. C’est le système du livre transformé en voix de rappel, pour les jours où le beatmaker sait ce qu’il doit faire mais a besoin qu’on le lui redise simplement.

# Annexe S — Checklist W-8BEN pas à pas

## Objectif

Cette annexe complète l’Annexe Q. Elle sert à préparer les informations nécessaires avant de remplir un formulaire W-8BEN ou un formulaire fiscal équivalent sur une plateforme américaine, un distributeur, une librairie musicale, un service de royalties ou un label étranger.

Le W-8BEN concerne en principe les personnes physiques non américaines. Une société ou entité utilise généralement un autre formulaire, comme le W-8BEN-E. Vérifiez toujours votre situation réelle avant de valider.

## Pourquoi c’est important

Sans formulaire fiscal correctement rempli, certains payeurs américains peuvent appliquer une retenue à la source élevée, souvent présentée comme pouvant aller jusqu’à 30 % selon le type de revenu et la situation. Le formulaire sert à établir votre statut de personne étrangère et, si applicable, à demander le bénéfice d’une convention fiscale.

**Règle simple :** ne laissez pas une plateforme étrangère choisir par défaut votre fiscalité parce que vous n’avez rien rempli.

## Avant de commencer

Préparez :

* votre nom légal complet ;
* votre pays de citoyenneté ;
* votre adresse de résidence permanente ;
* votre adresse postale si différente ;
* votre pays de résidence fiscale ;
* votre numéro fiscal français si vous en avez un ;
* votre date de naissance ;
* le nom de la plateforme ou du payeur ;
* le type de revenu concerné : royalties, licence, distribution, sync, paiement de label ;
* vos informations bancaires si la plateforme les demande séparément.

## Partie I — Identification

### Ligne 1 — Nom

Indiquez votre nom légal, pas seulement votre nom d’artiste.

**Erreur à éviter :** mettre uniquement votre blaze de beatmaker si la plateforme demande votre identité fiscale.

### Ligne 2 — Pays de citoyenneté

Indiquez votre pays de citoyenneté.

### Ligne 3 — Adresse de résidence permanente

Indiquez votre vraie adresse de résidence fiscale. N’utilisez pas une boîte postale si le formulaire demande une adresse permanente.

### Ligne 4 — Adresse postale

À remplir seulement si elle est différente.

### Ligne 5 — U.S. taxpayer identification number

Si vous n’avez pas de numéro fiscal américain, cette ligne peut être vide selon les cas. Certaines plateformes peuvent demander un ITIN pour certains avantages spécifiques. Ne l’inventez jamais.

### Ligne 6 — Foreign tax identifying number

Indiquez votre numéro fiscal étranger si demandé. En France, il peut s’agir du numéro fiscal personnel. Pour une société, la logique peut être différente.

### Ligne 7 — Reference number

Souvent facultatif. Certaines plateformes y mettent un identifiant client, compte artiste ou vendor ID.

### Ligne 8 — Date de naissance

Respectez le format demandé. Les plateformes américaines utilisent parfois le format mois / jour / année.

**Erreur à éviter :** inverser jour et mois si le formulaire impose un format américain.

## Partie II — Convention fiscale

Cette partie sert à demander l’application d’une convention fiscale si vous y êtes éligible.

Vous devez généralement indiquer :

* votre pays de résidence fiscale ;
* l’article de convention concerné si la plateforme le demande ;
* le taux réduit si applicable ;
* le type de revenu concerné.

Ne remplissez pas cette partie au hasard. Une mauvaise demande peut être refusée ou créer une incohérence.

**Phrase pratique :** si vous ne comprenez pas quel article utiliser, demandez à la plateforme, à un comptable ou à un fiscaliste. Ne copiez pas un exemple trouvé en ligne sans savoir s’il correspond à votre revenu.

## Partie III — Certification

Avant de signer, vérifiez que :

* le nom est correct ;
* le pays est correct ;
* l’adresse est correcte ;
* le numéro fiscal est correct ;
* la date de naissance est correcte ;
* la convention fiscale demandée, si utilisée, est cohérente ;
* vous signez en votre nom ou avec la qualité autorisée.

La signature certifie des informations fiscales. Ne signez pas pour une société si le formulaire concerne votre personne physique, et inversement.

## Après envoi

Conservez :

* copie du formulaire ;
* date d’envoi ;
* plateforme concernée ;
* accusé de réception ;
* capture de validation ;
* taux de retenue affiché ;
* date de renouvellement à prévoir.

## Validité et renouvellement

Un formulaire W-8BEN reste généralement valable de la date de signature jusqu’au dernier jour de la troisième année civile suivante, sauf changement de situation. Si vous déménagez, changez de résidence fiscale ou modifiez votre structure, vérifiez si un nouveau formulaire doit être envoyé.

### Exemple simple

Vous signez un W-8BEN en 2027. Il peut être nécessaire de le renouveler avant la fin de la troisième année civile suivante, selon les règles applicables et les demandes de la plateforme.

## Pièges fréquents

* Confondre W-8BEN et W-8BEN-E.
* Mettre son nom d’artiste au lieu de son nom légal.
* Oublier le numéro fiscal étranger.
* Inverser jour et mois dans la date de naissance.
* Demander un taux réduit sans comprendre l’article de convention.
* Croire que le formulaire se transmet toujours à l’IRS : en pratique, il est généralement remis au payeur ou withholding agent.
* Ne pas garder de copie.
* Ne pas surveiller l’expiration.

## Checklist finale W-8BEN

* [ ] Je suis bien une personne physique non américaine.
* [ ] Je n’agis pas au nom d’une société qui devrait utiliser un autre formulaire.
* [ ] J’ai préparé mon nom légal.
* [ ] J’ai préparé mon adresse de résidence fiscale.
* [ ] J’ai préparé mon numéro fiscal.
* [ ] J’ai vérifié le format de date.
* [ ] J’ai compris si je demande ou non un bénéfice de convention fiscale.
* [ ] J’ai gardé une copie du formulaire.
* [ ] J’ai noté la plateforme concernée.
* [ ] J’ai noté une date de vérification / renouvellement.

**À retenir :** le W-8BEN n’est pas un détail administratif. C’est une barrière de sécurité contre des retenues fiscales mal anticipées.

# Annexe T — Glossaire des sigles et termes de label

## Objectif

Un contrat de label peut sembler clair parce qu’il utilise des mots courts. En réalité, certains termes concentrent beaucoup de conséquences juridiques et financières.

Cette annexe sert à décoder les expressions courantes avant de signer, négocier ou demander une relecture.

## Glossaire rapide

| Terme | Traduction / sens | Ce que vous devez vérifier |
| --- | --- | --- |
| Advance | Avance | Est-elle récupérable ? Sur quels revenus ? |
| Recoupable | Récupérable | Le label se rembourse avant de vous payer certaines royalties. |
| Recoupable expenses | Frais récupérables | Liste exacte des frais : clip, promo, mix, mastering, ads, attaché presse. |
| Non-recoupable | Non récupérable | Frais que le label ne récupère pas sur vos revenus. À obtenir par écrit. |
| Royalty rate | Taux de royalties | Pourcentage, base de calcul, brut ou net. |
| Net receipts | Recettes nettes | Revenus reçus après déductions. Vérifiez quelles déductions sont permises. |
| Gross revenue | Revenu brut | Montant avant déductions. Rarement la base finale, mais important à comprendre. |
| Accounting statement | Relevé de comptes | Document périodique qui détaille revenus, frais, solde, recoupement. |
| Accounting period | Période comptable | Mensuelle, trimestrielle, semestrielle. Conditionne vos paiements. |
| Audit right | Droit d’audit | Droit de vérifier les comptes. Vérifiez délai, coût, conditions. |
| Territory | Territoire | France, Europe, monde entier. Plus c’est large, plus l’engagement est lourd. |
| Term | Durée | Durée du contrat. Vérifiez renouvellements automatiques. |
| Option | Option | Possibilité pour le label d’ajouter un projet ou prolonger. À encadrer. |
| Exclusivity | Exclusivité | Peut vous empêcher de sortir ailleurs. Vérifiez le périmètre. |
| Master | Enregistrement final | Qui le possède ? Qui l’exploite ? Pendant combien de temps ? |
| Master purchase | Achat de master | Le label peut chercher à acquérir le master. Vérifiez si c’est une vente définitive. |
| Master license | Licence de master | Autorisation d’exploiter le master sans transfert total de propriété. |
| Distribution deal | Contrat de distribution | Le label distribue, mais ne possède pas forcément le master. À vérifier. |
| Label services | Services label | Distribution + promo + services, parfois sans cession lourde. Lire les frais. |
| Publishing | Édition | Droits liés à la composition. Ne pas confondre avec le master. |
| Administration deal | Administration éditoriale | Gestion / collecte de droits sans cession complète selon contrat. |
| Sync rights | Droits de synchronisation | Utilisation musique + image. Qui peut autoriser ? Qui touche quoi ? |
| Neighboring rights | Droits voisins | Droits liés au master et aux interprétations selon rôle et pays. |
| Controlled composition | Composition contrôlée | Clause pouvant limiter certaines royalties d’auteur dans certains contrats. À relire. |
| Cross-collateralization | Compensation croisée | Le label peut récupérer des frais d’un projet sur les revenus d’un autre. Très sensible. |
| Reserves | Réserves | Sommes gardées temporairement par le label contre retours, litiges ou ajustements. |
| Minimum commitment | Engagement minimum | Ce que le label promet vraiment : budget, sortie, promo. À écrire. |
| Delivery requirements | Conditions de livraison | Fichiers, stems, artwork, metadata, délais. |
| Release commitment | Obligation de sortie | Le label s’engage-t-il à sortir le projet ? Dans quel délai ? |
| Takedown | Retrait plateformes | Qui peut retirer le morceau ? Dans quelles conditions ? |
| Reversion | Retour des droits | Moment ou condition où certains droits reviennent à l’artiste / producteur. |
| First refusal | Premier refus | Le label peut avoir priorité sur vos prochains projets. À limiter. |
| Backend | Revenus futurs | Revenus après exploitation : royalties, sync, droits voisins, etc. |
| All-in deal | Deal global | Peut inclure plusieurs prestations dans un budget unique. Demander le détail. |
| Work for hire | Travail commandé | Peut impliquer une perte importante de droits selon pays et contrat. À faire relire. |

## Les 10 termes qui doivent vous faire ralentir

1. Recoupable expenses.
2. Cross-collateralization.
3. Master purchase.
4. Work for hire.
5. Worldwide exclusive.
6. In perpetuity.
7. Controlled composition.
8. Option period.
9. Net receipts après déductions non listées.
10. Transfer of rights.

## Phrase à envoyer quand un terme n’est pas clair

> Merci pour le contrat. Avant de répondre, pouvez-vous me confirmer en termes simples ce que recouvre exactement la clause “[nom de la clause]”, notamment sa durée, son territoire, les droits concernés, son impact sur le master, l’édition, les revenus et la sortie du contrat ?

## Règle finale

Un terme que vous ne comprenez pas n’est pas un détail. C’est peut-être le cœur du contrat.

**À retenir :** vous ne perdez pas une opportunité en demandant une explication. Vous perdez une opportunité quand vous signez ce que vous ne comprenez pas.

# Annexe V — Checklist avant de distribuer un morceau

## Objectif

Cette annexe sert à vérifier qu’un morceau est prêt avant d’être envoyé à un distributeur, un label, une plateforme ou une librairie musicale.

Distribuer un morceau trop tôt peut créer des erreurs difficiles à corriger : mauvais crédits, mauvais fichier, ISRC oublié, splits flous, sample non vérifié, mauvais artwork, mauvaise date ou conflit entre ayants droit.

## 1. Fichiers audio

* [ ] Le fichier final est validé.
* [ ] Le WAV est exporté proprement.
* [ ] Le fichier n’est pas saturé inutilement.
* [ ] La version masterisée est clairement identifiée.
* [ ] Les stems sont archivés si besoin.
* [ ] Une version instrumental est conservée.
* [ ] Une version clean existe si nécessaire.
* [ ] Une version radio edit existe si nécessaire.
* [ ] Le fichier porte un nom clair.

## 2. Artwork

* [ ] La cover est prête.
* [ ] Le format demandé par le distributeur est respecté.
* [ ] L’image ne contient pas de logo non autorisé.
* [ ] L’image ne contient pas de marque utilisée sans droit.
* [ ] Le titre et le nom d’artiste sont cohérents avec les métadonnées.
* [ ] Une version haute qualité est archivée.

## 3. Métadonnées

* [ ] Titre exact du morceau.
* [ ] Nom d’artiste principal.
* [ ] Featuring éventuel.
* [ ] Producteur / beatmaker crédité.
* [ ] Auteurs.
* [ ] Compositeurs.
* [ ] Éditeur si applicable.
* [ ] Genre principal.
* [ ] Sous-genre.
* [ ] Langue.
* [ ] Explicit / clean.
* [ ] BPM.
* [ ] Tonalité.

## 4. Identifiants

* [ ] ISRC attribué ou à générer.
* [ ] UPC de la sortie créé ou à générer.
* [ ] ISWC connu si l’œuvre est déjà déclarée.
* [ ] IPI des ayants droit disponible si nécessaire.
* [ ] Les codes sont notés dans le catalogue maître.

## 5. Droits et contrats

* [ ] Licence du beat signée ou accord écrit existant.
* [ ] Split sheet validée.
* [ ] Rôle de chacun clarifié.
* [ ] Propriété du master clarifiée.
* [ ] Producteur phonographique identifié.
* [ ] Artistes-interprètes identifiés.
* [ ] Accord de featuring signé si nécessaire.
* [ ] Accord de label ou distribution relu si applicable.

## 6. Samples et éléments externes

* [ ] Aucun sample non autorisé.
* [ ] Les loops utilisées sont autorisées commercialement.
* [ ] Les presets, voix, one-shots et éléments générés par IA sont conformes aux conditions d’utilisation.
* [ ] Les crédits obligatoires sont notés.
* [ ] Les restrictions sync/publicité sont vérifiées.

## 7. Distribution

* [ ] Distributeur choisi.
* [ ] Conditions du distributeur lues.
* [ ] Commission ou abonnement compris.
* [ ] Délai de livraison respecté.
* [ ] Territoires choisis.
* [ ] Date de sortie validée.
* [ ] Précommande activée ou non.
* [ ] Page artiste vérifiée.
* [ ] Liens de pré-save préparés si disponibles.

## 8. Fiscalité et paiements

* [ ] Moyen de paiement configuré.
* [ ] RIB / IBAN / PayPal / Stripe vérifié.
* [ ] Formulaire fiscal demandé par la plateforme complété si nécessaire.
* [ ] W-8BEN ou W-8BEN-E vérifié pour les plateformes américaines si applicable.
* [ ] Les frais et retenues potentielles sont compris.

## 9. Promotion minimale

* [ ] 3 contenus courts préparés.
* [ ] 1 visuel story préparé.
* [ ] 1 texte d’annonce préparé.
* [ ] 1 email ou message aux contacts proches préparé.
* [ ] Liens officiels à archiver le jour de sortie.
* [ ] Date de relance J+7 notée.
* [ ] Bilan J+30 prévu.

## Décision finale

Avant de cliquer sur “submit”, répondez :

1. Le fichier est-il le bon ?
2. Les crédits sont-ils justes ?
3. Les droits sont-ils écrits ?
4. Les samples sont-ils propres ?
5. Le distributeur et les coûts sont-ils compris ?
6. Le morceau est-il archivé dans le catalogue ?

Si une réponse est floue, ne distribuez pas encore.

**À retenir :** une sortie officielle n’est pas seulement un upload. C’est une mise en circulation juridique, fiscale, artistique et commerciale.

# Annexe W — Modèle de mise en demeure détaillé

## Avertissement

Ce modèle est pédagogique. Il ne remplace pas une lettre rédigée par un avocat. Pour un montant important, une exploitation commerciale sérieuse, un conflit international, un label structuré ou une situation agressive, faites relire avant envoi.

Une mise en demeure doit rester factuelle. Elle ne doit pas insulter, menacer à l’aveugle ou exagérer.

## Cas d’usage

Ce modèle peut être adapté pour :

* impayé de label ;
* absence de relevé de royalties ;
* non-paiement d’une licence ;
* utilisation d’un beat sans licence ;
* non-respect d’une clause de contrat ;
* absence de crédit malgré accord ;
* dépôt Content ID non autorisé ;
* refus de transmettre ISRC, distributeur ou informations nécessaires.

## Modèle

**Objet : Mise en demeure — [paiement / régularisation / retrait / transmission d’informations] concernant [titre du morceau / nom du beat]**

Madame, Monsieur,

Je soussigné(e) [Nom / Nom d’artiste / Société], vous contacte au sujet de [décrire la situation : contrat signé, licence, collaboration, morceau distribué, exploitation constatée].

Le [date], nous avons [signé un contrat / validé une licence / échangé au sujet du beat / constaté l’utilisation du morceau] intitulé :

**[Titre du beat ou du morceau]**

Références connues :

* Beat concerné : [nom du fichier / titre]
* Morceau concerné : [titre]
* Artiste : [nom]
* ISRC : [si connu]
* Distributeur : [si connu]
* Date de sortie : [si connue]
* Lien officiel : [URL]
* Contrat / licence : [date / référence]
* Montant dû ou demandé : [montant]

À ce jour, malgré [mes relances / nos échanges / les obligations prévues au contrat], la situation suivante demeure non régularisée :

[Décrire précisément le problème : absence de paiement, absence de reporting, usage sans licence, dépassement de licence, dépôt Content ID non autorisé, absence de crédit, refus de transmettre les informations, etc.]

Je vous mets donc en demeure de procéder, dans un délai de [8 / 15] jours à compter de la réception du présent courrier, à :

* [payer la somme de X €] ;
* [transmettre le relevé de royalties] ;
* [régulariser la licence] ;
* [retirer l’exploitation non autorisée] ;
* [corriger les crédits] ;
* [retirer la revendication Content ID] ;
* [transmettre l’ISRC, le distributeur, la date de sortie et les crédits exacts] ;
* [autre demande précise].

À défaut de réponse ou de régularisation dans ce délai, je me réserve le droit d’engager toute démarche utile pour faire valoir mes droits, notamment auprès des plateformes concernées, du distributeur, de mes conseils, ou de toute juridiction compétente, selon la situation.

Cette démarche a pour objectif de permettre une régularisation amiable, claire et traçable.

Je vous remercie de me répondre par écrit à l’adresse suivante : [email].

Veuillez agréer, Madame, Monsieur, l’expression de mes salutations distinguées.

[Nom]
[Adresse ou mentions utiles]
[Email]
[Téléphone si souhaité]
[Date]
[Signature]

* copie du contrat ou de la licence ;
* facture ;
* preuve de paiement ou absence de paiement ;
* captures d’écran ;

* preuve de propriété ou de création ;
* split sheet si applicable.

## Pièges à éviter

* écrire sous le coup de la colère ;
* inventer des montants ;
* menacer pénalement sans fondement ;
* publier la lettre sur les réseaux ;
* mélanger plusieurs demandes floues ;
* oublier le délai ;
* envoyer sans preuve ;
* accuser sans vérifier le contrat ;
* oublier de garder une copie.

## Version courte pour email préalable

> Bonjour [Nom],
>

>

>
> Cordialement,
> [Nom]

**À retenir :** une bonne mise en demeure n’est pas un coup de pression. C’est une demande claire, datée, prouvée et exploitable.

# Annexe X — Modèle de contrat de cession de droits / master

## Avertissement

Cette annexe est un modèle pédagogique. Une cession de droits peut avoir des conséquences lourdes : perte d’exploitation, perte de contrôle, transfert de revenus, exclusivité longue, territoire mondial, impossibilité de réutiliser un master ou une composition.

Ne signez jamais une cession importante sans relecture professionnelle. Ce modèle sert à comprendre les clauses, pas à remplacer un avocat.

## À quoi sert une cession ?

Une cession consiste à transférer certains droits à une autre personne ou structure. Dans le music business, elle peut concerner :

* le master ;
* certains droits d’exploitation ;
* une part de revenus ;
* une exploitation sur un territoire ;
* une durée donnée ;
* une utilisation précise ;
* parfois une exclusivité.

**Règle simple :** une licence autorise. Une cession transfère. Ce n’est pas le même niveau de risque.

## Les clauses essentielles à vérifier

| Clause | Question à poser |
| --- | --- |
| Objet | Quels droits sont cédés exactement ? |
| Œuvre / master | Cède-t-on la composition, le master, ou seulement certains usages ? |
| Durée | Combien de temps dure la cession ? |
| Territoire | France, Europe, monde entier ? |
| Exclusivité | Puis-je encore exploiter ailleurs ? |
| Prix / avance | Le montant est-il fixe, recoupable, non recoupable ? |
| Royalties | Reste-t-il une part de revenus après la cession ? |
| Frais | Quels frais peuvent être déduits ? |
| Reporting | À quelle fréquence les comptes sont-ils transmis ? |
| Audit | Puis-je vérifier les comptes ? |
| Crédits | Comment mon nom apparaît-il ? |
| ISRC / métadonnées | Qui contrôle les identifiants et les crédits ? |
| Droit de retrait | Puis-je récupérer les droits en cas d’inexploitation ? |
| Droit applicable | Quel pays et quel tribunal en cas de conflit ? |

**Contrat de cession de droits / master**

**Le cédant :**

* céder “tous droits, pour le monde entier, pour la durée légale” sans comprendre ;
* accepter des frais recoupables illimités ;
* laisser “net receipts” sans définition ;
* oublier le droit d’audit ;
* ne pas préciser l’ISRC ;
* confondre avance et paiement définitif ;
* céder la composition alors que seule l’exploitation du master était prévue ;
* signer une version anglaise non relue ;
* céder une exclusive pour un montant symbolique.

**À retenir :** une cession peut être légitime. Mais elle doit être précise, limitée, payée et comprise.

# Annexe Z — Phishing, faux labels et arnaques music business

## Objectif

Cette annexe rassemble les réflexes de sécurité à garder face aux fausses opportunités.

Le music business attire les rêves, donc il attire aussi les escroqueries. Plus vous êtes visible, plus vous pouvez recevoir des messages qui jouent sur votre désir de reconnaissance.

## Les arnaques fréquentes

| Arnaque | Signal d’alerte |
| --- | --- |
| Faux label | Email gratuit, site douteux, demande de frais |
| Faux manager | Promet un placement sans contrat |
| Faux superviseur sync | Demande de payer pour soumettre |
| Faux distributeur | Lien de connexion suspect |
| Faux support plateforme | Demande de mot de passe |
| Faux concours | Frais d’inscription disproportionnés |
| Faux playlisting | Garantie de streams ou playlist officielle |
| Faux acheteur de beats | Demande stems avant paiement |
| Faux formulaire fiscal | Demande de données bancaires hors plateforme officielle |
| Faux virement | Capture de paiement sans fonds reçus |

## Règle des 5 vérifications

Avant de cliquer, payer, signer ou envoyer des stems :

1. **Domaine email**
   Vérifiez que l’adresse correspond au site officiel.

2. **Identité**
   Cherchez le nom de la personne sur plusieurs sources.

3. **Société**
   Vérifiez que la structure existe.

4. **Demande**
   Analysez ce qu’on vous demande réellement : argent, stems, données, signature, accès.

5. **Canal officiel**
   Recontactez l’organisme depuis son site officiel, pas depuis le lien reçu.

## Ce qu’un vrai professionnel ne demande pas

Un vrai professionnel ne devrait pas vous demander :

* votre mot de passe ;
* un paiement urgent pour être signé ;
* des stems complets avant accord ;
* une pièce d’identité par DM sans cadre ;
* une signature immédiate sans contrat lisible ;
* vos accès distributeur ;
* une connexion via un lien suspect ;
* une avance de frais impossible à justifier.

## Que faire en cas de doute ?

* ne cliquez plus ;
* ne répondez plus sous pression ;
* capturez les messages ;
* vérifiez le domaine ;
* contactez la vraie structure ;
* changez vos mots de passe si besoin ;
* activez la double authentification ;
* contactez votre banque si paiement ou coordonnées bancaires transmis ;
* signalez le message selon les canaux adaptés ;
* demandez conseil avant toute relance.

## Dossier de preuves

Créez un dossier :

`ARNAQUE_PHISHING_[DATE]_[NOM]`

Avec :

* captures du message ;
* email complet ;
* adresse expéditeur ;
* liens reçus ;
* documents envoyés ;
* captures de profil ;
* preuve de paiement si concerné ;
* échanges ;
* actions déjà faites.

## Mini-script de réponse prudente

> Bonjour,
>
> Pour des raisons de sécurité, je ne clique pas sur les liens externes et je ne transmets pas de fichiers exploitables avant vérification.
>
> Merci de me communiquer votre identité complète, votre société, votre site officiel, votre adresse email professionnelle et le cadre précis de votre demande.

## Mini-script de clôture

> Bonjour,
>
> Après vérification, je ne peux pas confirmer l’authenticité de cette demande. Je ne donnerai donc pas suite. Merci de ne plus me contacter concernant cette proposition.

## À retenir

La meilleure protection contre l’arnaque n’est pas la méfiance permanente. C’est une méthode.

Ralentir, vérifier, archiver, demander un écrit.

**Phrase finale :** une vraie opportunité survit à une vérification. Une arnaque insiste pour l’éviter.

# Annexe AA — Modèle de contrat de synchronisation simple

**Avertissement :** ce modèle est pédagogique. Il ne remplace pas un contrat rédigé ou relu par un avocat. La synchronisation peut impliquer des enjeux importants : publicité, marque, film, jeu vidéo, territoire, durée, exclusivité, droits d’auteur, master, interprètes, samples et sociétés de gestion.

## Objectif

Un contrat de synchronisation autorise l’utilisation d’une musique avec une image.

Cela peut concerner :

* publicité ;
* vidéo de marque ;
* contenu sponsorisé ;
* film ;
* documentaire ;
* jeu vidéo ;
* trailer ;
* émission ;
* vidéo YouTube monétisée ;
* campagne TikTok, Instagram ou Meta Ads ;
* événement filmé.

Le point important : une licence de beat classique ne couvre pas automatiquement une utilisation publicitaire ou audiovisuelle.

## Clauses essentielles à vérifier

### 1. Parties

Identifiez clairement :

* le beatmaker ou producteur ;
* l’artiste si le morceau est déjà finalisé ;
* la marque ;
* l’agence ;
* la société de production ;
* la personne qui signe réellement.

Ne signez pas avec “l’équipe” ou “le projet” sans entité identifiable.

### 2. Musique concernée

Indiquez :

* titre ;
* version ;
* durée utilisée ;
* ISRC si disponible ;
* auteurs / compositeurs ;
* producteur du master ;
* existence ou absence de samples ;
* fichier livré.

### 3. Usage autorisé

Le contrat doit dire précisément où la musique peut être utilisée :

* publicité web ;
* télévision ;
* cinéma ;
* réseaux sociaux ;
* événement ;
* site de marque ;
* podcast ;
* jeu vidéo ;
* bande-annonce ;
* contenu interne.

Une phrase vague comme “tous usages” doit être relue avec prudence.

### 4. Durée

Exemples :

* 3 mois ;
* 6 mois ;
* 1 an ;
* 2 ans ;
* perpétuel.

Plus la durée est longue, plus la rémunération doit être sérieuse.

### 5. Territoire

Exemples :

* France ;
* Europe ;
* monde entier ;
* pays précis ;
* plateformes mondiales uniquement.

Un usage mondial n’a pas la même valeur qu’un usage local.

### 6. Supports

Précisez :

* TV ;
* web ;
* réseaux sociaux ;
* cinéma ;
* radio ;
* affichage vidéo ;
* plateformes publicitaires ;
* événements ;
* usage interne.

### 7. Exclusivité

Une synchronisation peut être :

* non exclusive ;
* exclusive sur un secteur ;
* exclusive sur une durée ;
* exclusive sur un territoire ;
* exclusive totale.

Ne donnez pas d’exclusivité sans comprendre ce que vous bloquez.

### 8. Rémunération

Indiquez :

* montant fixe ;
* échéance de paiement ;
* acompte éventuel ;
* devise ;
* taxes ;
* frais ;
* pénalités de retard si applicable.

Ne livrez pas les fichiers définitifs sans écrit clair si l’usage est commercial.

### 9. Crédits

Dans certains usages publicitaires, le crédit n’est pas toujours affiché. Mais il doit être discuté.

Phrase possible :

> Crédit recommandé : “Music by [Nom]”, lorsque le support permet l’affichage de crédits.

### 10. Droits conservés

Le contrat doit préciser que vous ne cédez pas tout sauf mention claire.

Phrase pédagogique :

> La présente autorisation concerne uniquement l’utilisation de la musique synchronisée avec le contenu décrit au contrat. Elle ne constitue pas une cession générale de l’œuvre, du master ou du catalogue du beatmaker.

## Modèle court de clause

> Le concédant autorise le licencié à synchroniser le titre “[Titre]” avec le contenu audiovisuel intitulé “[Projet]”, exclusivement pour les supports suivants : [supports], pour le territoire suivant : [territoire], pendant une durée de [durée], à compter du [date], moyennant une rémunération de [montant]. Toute autre utilisation devra faire l’objet d’un accord écrit séparé.

## Pièges à éviter

* signer “tous droits, tous supports, monde entier, durée légale” pour un petit montant ;
* oublier le territoire ;
* oublier la durée ;
* céder le master au lieu d’autoriser une synchronisation ;
* autoriser une publicité alors que le beat contient un sample non vérifié ;
* laisser une agence utiliser la musique pour plusieurs clients ;
* accepter une exclusivité qui bloque votre catalogue ;
* livrer stems et versions alternatives sans encadrer leur usage.

## Checklist express avant de signer une sync

* [ ] Le projet audiovisuel est identifié.
* [ ] La marque ou société est clairement nommée.
* [ ] Le titre musical est identifié.
* [ ] La durée d’utilisation est écrite.
* [ ] Le territoire est écrit.
* [ ] Les supports sont écrits.
* [ ] L’exclusivité est claire.
* [ ] Le montant est clair.
* [ ] Le calendrier de paiement est clair.
* [ ] Les samples sont vérifiés.
* [ ] Les splits sont clairs.
* [ ] Le master est clairement attribué.
* [ ] Les fichiers livrés sont listés.
* [ ] Le contrat ne cède pas tout votre catalogue.
* [ ] Vous avez demandé une relecture si l’enjeu est important.

**Phrase finale :** une synchronisation peut être une belle opportunité. Mais une mauvaise sync peut bloquer un titre, un master ou une partie de votre catalogue pendant longtemps.

# Annexe AB — Checklist avant d’envoyer un DM

## Objectif

Un DM n’est pas un cri dans le vide. C’est une micro-proposition professionnelle.

Avant d’écrire à un artiste, un manager, un label, un superviseur musical ou un créateur, vérifiez que votre message mérite d’être lu.

## Avant d’envoyer

* [ ] J’ai écouté au moins un morceau récent de la personne.
* [ ] Je sais pourquoi je la contacte.
* [ ] Je peux citer un détail précis.
* [ ] J’ai préparé un lien privé propre.
* [ ] Le lien contient peu de beats, pas 80 fichiers.
* [ ] Les beats sont nommés correctement.
* [ ] Les BPM et tonalités sont disponibles.
* [ ] Mes prix sont prêts si la personne répond.
* [ ] Je n’envoie pas de stems au premier message.
* [ ] Je n’envoie pas de fichier ZIP lourd non demandé.
* [ ] Je ne promets pas un placement irréaliste.
* [ ] Je ne copie-colle pas le même message à tout le monde.

## Structure du bon DM

1. Salutation simple.
2. Preuve que vous avez écouté.
3. Proposition courte.
4. Lien privé ou proposition d’envoi.
5. Sortie sans pression.

### Exemple

> Salut [Prénom], j’ai écouté [titre]. J’aime bien la façon dont ta voix se pose sur les prods sombres, surtout sur [détail précis].
>
> J’ai 3 beats dans une vibe [style/mood] qui pourraient coller à ton univers.
>
> Si tu veux, je peux t’envoyer un lien privé. Aucune pression.

## Ce qu’il ne faut pas envoyer

* “Yo bro j’ai des prods, check mon lien.”
* “J’ai le son qui va te faire percer.”
* “Réponds vite, j’ai d’autres artistes dessus.”
* “Voici mes stems.”
* “Je t’envoie tout mon catalogue.”
* “Je fais comme [artiste connu].”
* “Tu peux me faire de la visibilité ?”

## Après l’envoi

* [ ] Je note la personne dans mon CRM.
* [ ] Je note la date du message.
* [ ] Je programme une relance douce.
* [ ] Je ne relance pas trois fois en 24h.
* [ ] Si la personne répond, je reste clair sur les prix et licences.
* [ ] Si la personne ne répond pas, je passe au prospect suivant sans insister.

## Relance douce

> Salut [Prénom], je me permets une petite relance pour ma proposition de beats.
>
> Aucune pression. Si ce n’est pas le bon moment, aucun souci. Je peux aussi t’envoyer une sélection plus ciblée selon ta prochaine direction.

## Règle simple

Un bon DM ne cherche pas à vendre immédiatement. Il cherche à ouvrir une conversation propre.

**Phrase finale :** la prospection n’est pas du spam quand elle est ciblée, respectueuse et suivie.

# Annexe AC — Version internationale anglaise : plan d’adaptation

## Objectif

La version anglaise ne doit pas être une traduction mot à mot.

Le marché anglophone a ses propres codes :

* beat leasing plus développé ;
* vocabulaire contractuel différent ;
* plateformes différentes ;
* fiscalité différente ;
* culture sync plus structurée ;
* rôle important des managers, publishers, labels et libraries ;
* attentes différentes sur les licences.

Une bonne version internationale doit adapter, pas simplement traduire.

## Titre de travail

**Independent Beatmaker 2027**
**Organize, Sell and Protect Your Beats in the AI Era**

Sous-titre possible :

**Licenses · Distribution · ISRC · Neighboring Rights · Sync · Labels · W-8BEN · Catalog Systems**

## Ce qu’il faut adapter

### 1. Vocabulaire

Remplacer ou expliquer :

* beatmaker / producer ;
* licence / license ;
* cession / assignment ;
* droits voisins / neighboring rights ;
* société de gestion / CMO ;
* producteur phonographique / master owner or recording rightsholder ;
* rémunération équitable / equitable remuneration ;
* mise en demeure / formal demand letter.

### 2. Exemples

Adapter les cas :

* France → USA / UK / Canada / Nigeria / global ;
* SACEM → PROs selon pays : ASCAP, BMI, SESAC, PRS, SOCAN selon contexte ;
* SCPP / SPPF → master rights / neighboring rights organizations ;
* ADAMI / SPEDIDAM → performer rights organizations selon territoire ;
* micro-entreprise → sole proprietor / self-employed selon pays.

### 3. Fiscalité

Ne pas transposer la fiscalité française.

Prévoir une annexe séparée :

* W-8BEN ;
* W-8BEN-E ;
* withholding tax ;
* tax treaty ;
* payer / withholding agent ;
* invoices ;
* accounting records ;
* local tax advisor disclaimer.

### 4. Contrats

Adapter les modèles :

* non-exclusive beat license ;
* unlimited license ;
* exclusive license ;
* sync license ;
* split sheet ;
* master assignment ;
* producer agreement ;
* demand letter.

### 5. Ton

Le ton peut rester direct, mais certaines formules doivent être adaptées.

En français, le livre peut dire : “ne signez pas n’importe quoi”.

En anglais, on peut écrire :

> Do not let excitement sign before your brain has read the deal.

## Structure recommandée

La version anglaise peut garder la structure V13 :

* mindset and roles ;
* gear without distraction ;
* sellable beats ;
* catalog system ;
* licenses and pricing ;
* rights and protection ;
* visibility and outreach ;
* global markets ;
* 90-day action plan ;
* passive income and diversification ;
* annexes.

## Ce qu’il ne faut pas faire

* traduire les références juridiques françaises comme si elles étaient universelles ;
* conserver uniquement SACEM / SCPP / ADAMI sans équivalents ;
* promettre une récupération automatique de droits voisins ;
* oublier les différences USA / UK / Canada ;
* traduire “mise en demeure” sans expliquer la logique ;
* utiliser des exemples de prix sans contexte de marché.

## Produit possible

La version anglaise peut devenir un produit séparé :

* ebook international ;
* toolkit anglais ;
* pack de contrats anglais ;
* companion audio anglais ;
* mini-course ;
* bundle “Global Beatmaker System”.

## Phrase finale

Traduire ce livre, ce n’est pas changer la langue. C’est changer le marché.



# Annexe AD — Modèle de contrat de producteur

**Avertissement :** cette annexe est pédagogique. Un vrai contrat de producteur doit être adapté au pays, au projet, au budget, au rôle réel de chacun et relu par un professionnel.

## À quoi sert ce contrat ?

Ce modèle sert quand le beatmaker ne vend pas seulement une licence, mais participe réellement à la production d’un morceau complet : direction musicale, arrangement, choix artistiques, organisation des fichiers, accompagnement studio, coordination du mix, parfois financement ou exploitation du master.

Dans ce cas, le beatmaker peut être plus qu’un vendeur de beat. Il peut devenir producteur musical, co-producteur, réalisateur artistique, producteur exécutif ou producteur phonographique selon les faits et le contrat.

Le but du contrat est d’éviter la phrase dangereuse : “On verra après.”

## Informations de base

**Titre provisoire du morceau :** [Titre]

**Artiste :** [Nom artiste]

**Producteur / beatmaker :** [Nom]

**Date de début de collaboration :** [Date]

**Projet concerné :** single / EP / album / sync / campagne / autre

## Rôle du producteur

Le producteur intervient sur :

* création ou fourniture du beat ;
* arrangement ;
* direction artistique ;
* préparation des sessions ;
* enregistrement ;
* choix des versions ;
* coordination mix/master ;
* suivi de distribution ;
* accompagnement de sortie ;
* autre : [à préciser].

**Clause simple :**

> Le producteur participe à la création et/ou à la réalisation du morceau intitulé provisoirement “[Titre]”. Son rôle exact est décrit dans le présent accord afin de distinguer la composition, la production musicale, l’exploitation du master et les éventuels droits voisins.

## Composition et splits

La composition doit être séparée du master.

| Personne | Rôle | Pourcentage composition |
| --- | --- | ---: |
| [Nom] | Beatmaker / compositeur instrumental | [ ] % |
| [Nom] | Auteur / interprète | [ ] % |
| [Nom] | Topliner | [ ] % |
| [Nom] | Co-producteur | [ ] % |

Une split sheet doit être annexée au contrat.

## Master et exploitation

Définissez clairement qui possède ou exploite le master.

Questions à écrire :

* Qui finance l’enregistrement ?
* Qui paie le mix ?
* Qui paie le mastering ?
* Qui choisit le distributeur ?
* Qui possède le master final ?
* Qui reçoit les revenus de distribution ?
* Qui peut autoriser une synchronisation ?
* Qui peut retirer le morceau ?
* Qui gère les ISRC et UPC ?

**Clause simple :**

> Les parties conviennent que le master final sera exploité par [nom / structure]. Les revenus issus de l’exploitation du master seront répartis selon le tableau financier annexé, après déduction éventuelle des frais expressément acceptés par écrit.

## Budget, avances et frais

| Frais | Payé par | Recoupable ? | Justificatif requis ? |
| --- | --- | --- | --- |
| Beat / production | [ ] | Oui / Non | Oui / Non |
| Studio | [ ] | Oui / Non | Oui / Non |
| Mix | [ ] | Oui / Non | Oui / Non |
| Mastering | [ ] | Oui / Non | Oui / Non |
| Artwork | [ ] | Oui / Non | Oui / Non |
| Promo | [ ] | Oui / Non | Oui / Non |

**Règle simple :** aucun frais recoupable ne doit être vague. Si quelqu’un peut le récupérer sur les revenus futurs, il doit être écrit, plafonné ou justifié.

## Validation artistique

Définissez qui valide :

* version finale ;
* mix ;
* mastering ;
* artwork ;
* date de sortie ;
* crédits ;
* clip ;
* version radio ;
* remix ;
* synchronisation.

**Clause simple :**

> Aucune version finale ne pourra être distribuée commercialement sans validation écrite des crédits, des splits, du master, de l’ISRC et de la répartition financière.

## Crédits

Crédit recommandé :

> Produit par [Nom]

ou :

> Prod. by [Nom]

ou :

> Réalisation artistique : [Nom]

Choisissez la formulation qui correspond au rôle réel.

## IA, samples et Content ID

Le contrat doit préciser :

* interdiction ou autorisation encadrée de l’usage IA ;
* interdiction d’entraîner un modèle avec les fichiers livrés ;
* responsabilité sur les samples ;
* règles Content ID ;
* autorisation ou non de remix automatisé ;
* limites de réutilisation des stems.

## Signature

Fait à : [Ville]

Date : [Date]

Signature artiste : ______________________

Signature producteur : ______________________

## À retenir

Un contrat de producteur ne sert pas à “faire sérieux”. Il sert à dire qui fait quoi, qui possède quoi, qui paie quoi, qui récupère quoi et qui décide quoi.

# Annexe AE — Checklist avant d’envoyer un beat à un label

## Objectif

Cette checklist intervient avant l’envoi d’un beat à un label, un manager, un éditeur, une agence de placement ou un A&R.

Elle est différente de la checklist “avant de répondre à une offre de label”. Ici, vous n’avez pas encore de proposition. Vous préparez l’envoi pour ne pas donner trop, trop vite, trop flou.

## 1. Vérifier le beat

* [ ] Le beat est terminé.
* [ ] Le beat est nommé proprement.
* [ ] BPM et tonalité sont connus.
* [ ] Le style et le mood sont clairs.
* [ ] La structure est exploitable.
* [ ] La version envoyée n’est pas un brouillon.
* [ ] Le fichier ne s’appelle pas `final_final_v3.wav`.

## 2. Vérifier les droits

* [ ] Aucun sample risqué non autorisé.
* [ ] Les loops utilisées sont licenciées pour usage commercial.
* [ ] Les co-producteurs sont identifiés.
* [ ] Les splits sont discutés ou prêts à être discutés.
* [ ] Vous savez si le beat est disponible, déjà leasé, réservé ou exclusif.
* [ ] Aucun artiste n’a déjà une option prioritaire dessus.

## 3. Préparer les fichiers à envoyer

Envoyez d’abord une version d’écoute, pas tout votre coffre-fort.

* [ ] MP3 preview propre.
* [ ] Watermark ou tag si nécessaire.
* [ ] Pas de stems au premier contact.
* [ ] Pas de session DAW.
* [ ] Pas de fichiers MIDI sensibles.
* [ ] Pas de WAV haute qualité sans cadre si le label n’a rien demandé officiellement.

## 4. Préparer les métadonnées

* [ ] Titre du beat.
* [ ] BPM.
* [ ] Tonalité.
* [ ] Style.
* [ ] Mood.
* [ ] Nom du beatmaker.
* [ ] Contact.
* [ ] Disponibilité : non exclusif / exclusif / collaboration.
* [ ] Mention “no uncleared samples” si c’est vrai.

## 5. Préparer le lien privé

* [ ] Lien SoundCloud privé, Disco, Dropbox, Drive ou page privée.
* [ ] Accès limité.
* [ ] Pas de dossier ouvert avec tout votre catalogue.
* [ ] Nom du dossier propre.
* [ ] 3 à 5 beats maximum si vous envoyez une sélection.
* [ ] Aucun fichier sensible dans le dossier.

## 6. Préparer le message

Message court :

> Bonjour [Prénom],
>
> Je vous envoie une sélection courte de [nombre] beats dans une direction [style/mood].
>
> Chaque titre est prêt pour écoute, avec BPM et tonalité indiqués. Les stems et conditions d’exploitation peuvent être transmis si un titre vous intéresse sérieusement.
>
> Lien privé : [lien]
>
> Merci pour votre écoute,
> [Signature]

## 7. Ce qu’il ne faut pas faire

* envoyer 40 beats ;
* envoyer des stems sans accord ;
* envoyer une session complète ;
* dire “faites ce que vous voulez avec” ;
* promettre une exclusivité sans prix ;
* envoyer un beat avec sample non autorisé ;
* accepter une modification orale des conditions ;
* confondre intérêt d’un label et contrat signé.

## 8. Après l’envoi

* [ ] Notez la date d’envoi.
* [ ] Notez le contact exact.
* [ ] Notez les beats envoyés.
* [ ] Programmez une relance douce à J+7 ou J+10.
* [ ] Archivez la réponse.
* [ ] Ne renvoyez pas les mêmes beats ailleurs en exclusivité tant que la discussion est active sans clarifier.

## À retenir

Un label n’a pas besoin de recevoir toute votre matière pour comprendre votre niveau.

Votre premier envoi doit donner envie, pas vous mettre à nu.

# Annexe AF — Companion audio / podcast : version de production

## Objectif

Le companion audio transforme le livre en expérience d’accompagnement. Il ne remplace pas le livre. Il aide le lecteur à passer à l’action.

# Annexe AN — Contrat de management : points à vérifier

## Le problème

Un manager peut aider un beatmaker à trouver des placements, négocier, organiser les relations avec artistes, labels, éditeurs ou marques. Mais un mauvais contrat de management peut prendre beaucoup de contrôle pour peu de résultats.

## Points clés

| Point | À vérifier |
| --- | --- |
| Commission | Pourcentage exact, base de calcul, revenus concernés |
| Durée | Durée initiale, renouvellement automatique ou non |
| Territoire | France, monde, certains pays seulement |
| Exclusivité | Le manager représente-t-il tous vos projets ou seulement certains ? |
| Frais | Qui paie déplacements, promo, studio, représentation ? |
| Objectifs | Y a-t-il des objectifs minimums ? |
| Reporting | Fréquence des comptes rendus |
| Résiliation | Sortie possible si aucun résultat |
| Conflit d’intérêts | Le manager représente-t-il aussi des labels ou artistes impliqués ? |

## Clause de prudence

> Aucun frais ne sera engagé au nom du beatmaker sans accord écrit préalable. Les commissions du manager ne seront dues que sur les revenus effectivement encaissés, sauf clause contraire expressément acceptée.

**À retenir :** un bon manager ouvre des portes. Un mauvais contrat ferme les vôtres.

# Annexe AP — Glossaire NFT / Web3 / blockchain

| Terme | Définition simple |
| --- | --- |
| NFT | Jeton numérique censé représenter un objet unique ou rare sur une blockchain |
| Web3 | Ensemble d’usages liés à blockchain, tokens, wallets, smart contracts |
| Blockchain | Registre numérique distribué qui enregistre des transactions |
| Smart contract | Programme automatisé exécutant certaines conditions sur blockchain |
| Wallet | Portefeuille numérique permettant de recevoir ou envoyer des crypto-actifs |
| Marketplace | Plateforme de vente ou échange de NFT |
| Gas fees | Frais de transaction sur certaines blockchains |
| Mint | Création d’un NFT sur une blockchain |
| Royalties NFT | Pourcentage éventuellement prévu à la revente, selon plateforme et règles techniques |
| Métavers | Environnement numérique persistant, souvent lié à avatars, objets virtuels ou événements |

**À retenir :** le vocabulaire Web3 peut donner une impression de nouveauté, mais les droits musicaux restent à écrire clairement.
