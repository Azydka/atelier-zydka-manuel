# Manuscript Studio by Atelier Zydka

## Transformez un manuscrit brut en pack éditorial complet

Manuscript Studio by Atelier Zydka est un mini-studio éditorial local qui transforme un manuscrit source en livrables prêts à diffuser :

- livre PDF ;
- teaser PDF ;
- citations marketing ;
- visuels réseaux sociaux ;
- rapport éditorial ;
- dossier de publication ;
- archive ZIP transmissible.

---

## Le problème

Vous avez un contenu long : guide, méthode, formation, manifeste, livre pratique ou document expert.

Mais le transformer en produit propre demande souvent trop d’étapes : mise en page, PDF, citations, visuels, teaser, dossier de livraison, vérification éditoriale et archive ZIP.

Résultat : le contenu existe, mais il reste difficile à présenter, tester ou vendre.

---

## La solution

Manuscript Studio by Atelier Zydka automatise le passage entre un manuscrit brut et un pack éditorial complet.

Commande principale :

    python3 make.py archive

Sortie principale :

    dist/atelier-zydka-manuel-release.zip

Cette séparation permet de montrer le moteur sans exposer le vrai produit éditorial.
