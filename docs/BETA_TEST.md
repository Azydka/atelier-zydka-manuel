# Bêta-test — Atelier Zydka Manuel

Version : V2.1 Early Access  
Statut : test utilisateur  
Date : 23/05/2026

---

## Objectif

Ce bêta-test sert à vérifier si Atelier Zydka Manuel est compréhensible, testable et utile pour une personne extérieure au projet.

L’objectif est de répondre à trois questions :

1. Est-ce que le produit est compréhensible ?
2. Est-ce que le ZIP est clair ?
3. Est-ce que les livrables donnent envie d’aller plus loin ?

---

## Ce que le testeur reçoit

Le fichier principal transmis est :

    atelier-zydka-manuel-release.zip

Il contient notamment :

- README.md ;
- RELEASE_NOTES.md ;
- LICENSE.md ;
- guide utilisateur ;
- FAQ ;
- page de vente ;
- PDF principal ;
- teaser PDF ;
- rapport éditorial ;
- citations marketing ;
- visuels réseaux sociaux.

## Ce qu’il faut tester

### 1. Compréhension générale

Ouvrir d’abord :

    README.md

Questions :

- Comprenez-vous ce que fait Atelier Zydka Manuel ?
- Comprenez-vous à quoi sert le projet ?
- Comprenez-vous la différence entre le moteur et le manuscrit de démonstration ?
- Le positionnement est-il clair ?

---

### 2. Documentation

Ouvrir ensuite :

    docs/GUIDE_UTILISATEUR.md
    docs/FAQ.md
    docs/PAGE_VENTE.md
    LICENSE.md

Questions :

- La FAQ répond-elle aux questions principales ?
- La page de vente donne-t-elle envie de tester l’outil ?
- La licence est-elle compréhensible ?
- Y a-t-il une information manquante ?

### 3. Livrables

    pdf/

- Le PDF principal est-il lisible ?
- Le teaser est-il utile ?
- Les citations marketing sont-elles propres ?
- Les visuels réseaux sont-ils exploitables ?

## Questions finales

Merci de répondre à ces 10 questions :

1. En une phrase, qu’avez-vous compris du produit ?
2. Le ZIP est-il clair ?
3. Le README suffit-il à comprendre le projet ?
4. Le guide utilisateur est-il utile ?
5. Les livrables générés sont-ils convaincants ?
6. Qu’est-ce qui vous semble le plus fort ?
7. Qu’est-ce qui vous semble le plus faible ?
8. L’absence d’interface graphique est-elle bloquante ?
9. Seriez-vous prêt à payer 39–49 € pour une version early access ?
10. Quelle amélioration prioritaire recommandez-vous ?

## Retour attendu

Le retour peut être envoyé sous forme :

- de texte libre ;

- de captures annotées ;
- de message vocal ;
- de tableau problème / suggestion.
